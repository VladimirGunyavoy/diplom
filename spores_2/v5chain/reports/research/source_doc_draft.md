## 1. Идея
Система ẋ = f(x, u). Берём только крайние управления u₁…u_K (для быстродействия оптимум bang-bang). Каждое u_k — **слой**.
Фазовое пространство покрываем **клетками** — небольшими плотными областями, вытянутыми вдоль траекторий одного слоя.
Клетки перекрываются (**атлас, не плитка**). Точка движется по клеткам, в любой момент может перейти в соседнюю клетку другого слоя
(= переключить управление). Выход метода — **коридор**: последовательность (dt_i, u_i) от старта к цели, которую затем оптимизирует
внешний оптимизатор (моменты переключения — непрерывные). Критерий обобщённый; сейчас — время.

## 2. Термины
- **Спора** — центр, из которого выросла клетка. **Клетка** — плотная область вокруг споры.
- **Точка-путешественник** — [ОТКРЫТО: название; предложено «фаг» — живёт на управлении клетки, перескакивает в соседнюю].
- **Сегмент** — отрезок через спору перпендикулярно полю (в нормированных координатах), полуширина r.
- **Стены** — траектории концов сегмента. **Вход / выход** (торцы) — сегмент, унесённый потоком на −τ / +τ.
- **Фронты** — сегмент, унесённый на kτ/n (поперечные линии внутри клетки, как в v4). **Соседи** — клетки, пересекающиеся с данной.

## 3. Клетка на двойном интеграторе (ẋ = v, v̇ = u, |u| ≤ 1)
Кривой четырёхугольник: стены — параболы x = c ± … + u·t²/2, вход/выход — **прямые** отрезки (поток при постоянном u аффинный).
Центр (0, 0), u = +1: сегмент горизонтален и не растягивается, стены x = ±r + t²/2. Центр (0, 2): длина торца относительно
исходной 0.89 / 1.0 / 1.61 при t = 0.5 / 1 / 2 — длину клетки ограничивает растяжение ρ_max, не угол поворота поля.
Размер клетки: конечный и небольшой (слово пользователя), ограничения — ρ_max, r_max, τ_max. Угол поворота поля — не критерий.

## 4. Атлас: соседи, V, переключение
- Клетка хранит соседей (перекрытия). Точка проверяет соседей.
- **V хранится по клеткам** (V во всех точках — дорого; в будущем — нейросеть). [ОТКРЫТО: где хранить — в центре (эвристика, если клетки
  малы) или несколько значений на выходе (предложение research: V(x) = время до выхода + V_выход(позиция поперёк), точнее за ту же цену)].
- **Переключение возможно в любой момент** (согласовано). [ОТКРЫТО: практически — на фронтах через каждые τ/n (предложение research):
  дискретно, погрешность ≤ τ/n, малые клетки = n = 1; оптимизатор коридора потом снимает дискретность.]
- Гарантии попадания нет — точка проверяет свой путь (прошла → посмотрела, где оказалась). Условие покрытия: выход каждой клетки
  лежит в ядрах соседей; нет — дыра, туда сеять новую спору. Для этого нужны **core/halo** (атлас, любая размерность;
  в v5-плитке гало не нужно). Вторая роль гало — запас на такт управления τ_ctrl·|F|.

## 5. Построение атласа (эллипс)
Эллипс с фокусами старт/цель, сначала почти отрезок. Клетки максимально допустимого размера в старте и цели, затем заполнение между
ними, клетки притираются друг к другу. Нет пути — растёт эксцентриситет. Приоритет спавна — как A*: (шаги от старта + шаги до цели),
лучше во времени. Эллипс — эвристика только для **центров спор**, тело клетки может выходить за эллипс.

## 6. Нормировка
Перпендикуляр к полю зависит от масштаба осей. По умолчанию: L — размер области, T — собственное время системы
(DI: √(L/a_max); маятник: √(l/g)); позиции / L, скорости / (L/T). DI, поле 4, a = 1: x/4, v/2. В Ursina — клавиша масштаба оси
скорости, смотреть глазами. Запасной вариант — автоматическая балансировка якобиана.

## 7. Коридор → оптимизатор
Коридор = (dt_i, u_i); оптимизация моментов переключения при фиксированной последовательности — известный приём
(Kaya & Noakes, time-optimal switching — **ссылку проверить**). V по клеткам — эвристика A*-поиска коридора; поле V (как в v5) —
обратная связь из любой точки, второй выход.

## 8. Слабые места
1. Интерполяция V между опорными точками — болезнь v5 на дифдрайве (цена не сходится по h); здесь смягчается оптимизатором коридора.
2. Экспонента по размерности; неголономные боковые сдвиги — цепочками переключений внутри клеток.
3. Параметры: r, τ, n, ρ_max, S, α (core/halo).

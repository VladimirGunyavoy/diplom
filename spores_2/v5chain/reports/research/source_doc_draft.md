## 1. Идея одним абзацем
Управляемая система ẋ = f(x, u). Берём только крайние управления u₁…u_K (принцип максимума: для быстродействия оптимум
bang-bang). Каждое u_k даёт своё поле F_k — **слой**. Фазовое пространство покрываем **спорами** — клетками, вытянутыми вдоль
траекторий одного слоя. Споры разных слоёв стыкуются там, где выгодно переключить управление. Путь = последовательность спор
с переключениями; ищется по графу. Исполнение: измерил состояние → нашёл спору → применил её u.

## 2. Пример: двойной интегратор (ẋ = v, v̇ = u, |u| ≤ 1)
- Слой «+» (u = +1): траектории — параболы x = c + v²/2, номер c сохраняется. Слой «−»: x = d − v²/2, d — точка остановки.
- **Спора в v4 (что видно в Ursina, `v4_ort/src/spores/ortho_grid.py`)** — строится вокруг `look_point`:
  1. центральная траектория: `n_tau` шагов по `tau/n_tau` вперёд и назад;
  2. поперечное сечение: `n_s` шагов длины `r_s/n_s` перпендикулярно полю (`_ortho_step`, направление пересчитывается);
  3. клоны — траектории из точек сечения;
  4. фронты — соединение одноимённых точек клонов; режимы TIME (равное время), ARC (равная дуга), ORTHO (фронт ⟂ потоку).
  Боковые стенки = крайние клоны = две параболы своего слоя ⇒ изнутри через них не вытечь (flow box, теорема единственности).
- Пример (0, 0), u = +1: поле (0, 1), сечение горизонтально (x = ±0.25, ±0.5); клоны — сдвинутые параболы; в TIME фронт
  в момент t — горизонтальный отрезок на высоте v = t, а поле там (t, 1) ⇒ фронт перекашивается относительно потока (сдвиг).
- **Атлас:** из (−2, 0) в (0, 0): «+» по параболе c = −2 до (−1, √2), переключение на «−» по d = 0 в цель. T = 2√2 ≈ 2.83 = T*.

## 3. Спора: из чего состоит
| часть | смысл | v4 | v5 |
|---|---|---|---|
| слой k | одно крайнее u | `OrthoGrid(u_sign)` | режим ±a |
| стенки | траектории своего слоя | крайние клоны | параболы c_i, c_{i+1} |
| торцы | где спора кончается | фронт TIME/ARC/ORTHO | параболы другого слоя d_j, d_{j+1} |
| размер | когда остановить рост | вручную (`tau`, `r_s`) | шаг решётки h |
| core/halo | ядро для стыковки / запас на такт исполнения | нет | нет |

**[РЕКОМЕНДАЦИЯ research — не утверждено] Торец = траектория другого слоя.** Тогда торец и есть линия переключения: ребро
«доехал до торца → переключился» точное, без карты Φ и без проверки «образ торца в ядре соседа». В 2D это даёт решётку (c, d)
v5 (точность в узлах 3e-8). Для n ≥ 3 — **гипотеза**: сечение ткать из траекторий других слоёв; проверить.

## 4. Атлас: граф и цена
- Узлы — точки переключения (пересечения стенок/торцов разных слоёв), рёбра — куски траекторий (цена = время) и переключения.
- **[РЕКОМЕНДАЦИЯ research — не утверждено] Цель метода — околооптимальное время:** цена T(узел) обратным Дейкстрой от цели
  (поле сразу для всех стартов), запрос из точки — интерполяция T в споре. Альтернатива из переписки — «коридор + затравка
  оптимизатору» (цена ребра = время прохода клетки, зависит от точки входа ⇒ ошибка порядка времени одной клетки).
- Поиск в эллипсе старт–цель не годится уже на DI: старт (1, 1.5) летит от цели и тормозит до x ≈ 2.1 (d = 2.125).

## 5. Исполнение
Замкнутое: измерил → спора → её u (или политика по T, `rollout`). Гало — запас на такт τ: толщина ≥ τ·|F|
(DI, v = 2, τ = 0.05: ≈ 0.11). Разомкнутый реплей в неустойчивых зонах не гарантирован (растяжение e^{λt}, переписка §5).

## 6. Когда формул траекторий нет (маятник, дифдрайв)
Спору растить численно (как v4): стенки из проинтегрированных траекторий гарантируют герметичность; проверять надо только
ошибку представления (стенки между узлами интегратора) и растяжение сечения ρ_max. **Угол поворота поля — не критерий
остановки** (на DI поле вдоль параболы поворачивается почти на 90° без вреда; в переписке два документа противоречат друг другу).
Метрика (нормировка осей S) нужна только для перпендикуляров/углов (режим ORTHO в v4 зависит от единиц v).

## 7. Слабые места / открытые вопросы
1. Ошибка интерполяции цены вне узлов — главная болезнь v5 на дифдрайве (цена с дугами не сходится по h; 5D +45–50%, пока
   рёбра не попадают в узлы). В переписке не рассмотрена (Φ и Π L_Φ контролируют выполнимость, не цену).
2. Складка v = 0 в координатах (c, d) и излом на кривой переключения (АТЛАС §7).
3. Экспонента по размерности (решётка/каркас 2^{n−1}); неголономные боковые сдвиги (скобки Ли) — через цепочки переключений.
4. Параметры не исчезли: h, τ, ρ_max, S.

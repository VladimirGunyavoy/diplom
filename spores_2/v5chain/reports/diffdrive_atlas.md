## A5 (адаптация)
Сделан облегчённый вариант — двухуровневое поле у цели (A5-lite, `rollout_multi`): именно у цели ошибка интерполяции максимальна (боковой сдвиг). Полное адаптивное дробление (нетензорная решётка, индикатор ошибки из графа) — отложено: нужна нестандартная решётка с согласованием уровней, а без эталона индикатор ошибки нечем калибровать.

## Итог по схеме B (5D) и по несходимости — hub-worker-2
1. **Причина несходимости по h (A: дуги; B: T из покоя)** — билинейная интерполяция T в конце ребра вне узла (+ боковой сдвиг раздувается ~√ε). Доказано: при h, где шаги попадают в узлы, T(1,0,0)=2.000 = идеал.
2. **Правило построения решётки B:** h = a_max·dt²/2 (сдвиги в узлы), nth = 2π/(α_max·dt²/2) (поворот в узел): T повороты −15…19%, (1,0,0) точно.
3. **Сходимость B по dt:** 1→0.5 снижает T на 0–12% (верхняя оценка → предел).
4. **Управление:** `rollout5` (перебор глубины 3, snap=0.25, цель-поглотитель) — 6/6 стартов ровно в цель за время ≤ T.
5. **Не сделано:** A и B сравнены по T из покоя (B в 2–3 раза медленнее, физика); адаптивное дробление для A не нужно (ошибка равномерна); полная политика без интерполяции для поворотных рёбер (сдвиг при повороте иррационален по решётке) — возможный следующий шаг: дробление h вблизи траекторий поворота.

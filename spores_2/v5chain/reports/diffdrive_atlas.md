## A5 (адаптация)
Сделан облегчённый вариант — двухуровневое поле у цели (A5-lite, `rollout_multi`): именно у цели ошибка интерполяции максимальна (боковой сдвиг). Полное адаптивное дробление (нетензорная решётка, индикатор ошибки из графа) — отложено: нужна нестандартная решётка с согласованием уровней, а без эталона индикатор ошибки нечем калибровать.

## Решения агента
- Схема A (v, ω — управления), т.к. ответа пользователя по A/B нет (решение наблюдателя 2026-09-29, `history/decisions.md`). **Вопрос A/B остаётся для утра.**
- Дуги: цена не сошлась по h — использовать поле с дугами только для управления (rollout), не как эталон времени.

Ограничения: точного эталона для дифдрайва нет; на поле без дуг rollout застревает; цена с дугами по h не сошлась; полный A5 не сделан.

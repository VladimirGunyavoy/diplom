# b26 — A* на графе дерева, статик кар (слово пользователя 12.11)
Код `car_astar.py` (копия b25-стека, ENV финального правила; запуск `runpc.sh car_astar.py NB 8 sel|test T0 T1`).
Алгоритм: из x — A* по 9 примитивам×τ.2 (точный rk), g = время, h = HW·V̂(q), V̂ = min_k W_k + KVA·d; закрытый список по хэш-решётке (ячейка .5·SC); зазор ≥ FM на ребре (1-й шаг + торможение как у жадного); лимит 300 раскрытий (пачками по 8), без раннего узла (EPS=0), берётся 1-е действие лучшего листа по g+h; перепланирование каждые .2 с.
Находка: W ранжирующая, занижает время ~35% (research-35) ⇒ h = V̂ (HW=1) хуже жадного (sel 1.14–1.33); взвешенный h (HW 1.5–2) и KVA=.3 — как жадный по медиане и лучше по максимуму. KVA=1 хуже (1.09/1.15).

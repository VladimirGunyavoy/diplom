# Алгоритм ветвей и область достижимости

## Система

Двойной интегратор:

```
ẍ = u,    |u| ≤ a_max
```

Состояние: `(x, ẋ) = (x, v)`. В коде: ось X — позиция, ось Z — скорость.

---

## Шаблоны и ветви

Каждая ветвь задаётся **шаблоном** `((u1_sign, t1_sign), (u2_sign, t2_sign))`:

- `u1_sign, u2_sign ∈ {+1, −1}` — знак управления в двух фазах, всегда противоположны
- `t1_sign, t2_sign ∈ {+1, −1}` — направление времени в каждой фазе

Всего **8 шаблонов** (2 знака u1 × 2 знака t1 × 2 знака t2).

Каждая ветвь содержит `n_tau + 1` **лучей** (rays). Луч с номером `k` — это траектория с моментом переключения в шаге `k`:

- шаги `1..k` : управление `u1_sign · a_max`, шаг по времени `dtau · t1_sign`
- шаги `k+1..n_tau` : управление `u2_sign · a_max`, шаг по времени `dtau · t2_sign`

При `k = 0` — чисто вторая фаза, при `k = n_tau` — чисто первая.

---

## Связь с теорией достижимости

**Достижимое множество** (reachable set) из состояния `x0` — это множество всех состояний, в которые система может попасть за заданное время `τ` при допустимых управлениях.

**Принцип максимума Понтрягина** утверждает: для задачи оптимального управления с ограниченным управлением `|u| ≤ a_max` оптимальное управление является **экстремальным** (принимает значения на границе допустимого множества). Для двойного интегратора — это управление типа «bang-bang»: `u ∈ {−a_max, +a_max}`.

Следствие: **граница достижимого множества** порождается исключительно bang-bang траекториями с не более чем одним переключением (для системы второго порядка). Перебирая момент переключения `k` от 0 до `n_tau`, мы **вметаем** лучами ровно эту границу.

Таким образом, каждая ветвь из 8 шаблонов строит один «кусок» границы достижимого множества.

---

## Прямое и обратное время

Шаблоны с `t_sign = +1` интегрируют **вперёд по времени** — это стандартное прямое достижимое множество: «куда можно попасть из `x0`».

Шаблоны с `t_sign = −1` интегрируют **назад по времени** — это **обратное достижимое множество** (backward reachable set): «из каких состояний можно попасть в `x0`».

Обратное достижимое множество вычисляется стандартным способом: интегрированием системы с обращённым временем, что эквивалентно смене знака производной по времени.

---

## Итог: полная картина

Перебирая все 8 шаблонов и варьируя момент переключения `k`, мы получаем:

| t1, t2   | u1, u2  | Смысл                                        |
|----------|---------|----------------------------------------------|
| +1, +1   | +, −    | Прямая достижимость, положительное → отрицательное управление |
| +1, −1   | +, −    | Прямая → обратная фаза                       |
| −1, +1   | +, −    | Обратная → прямая фаза                       |
| −1, −1   | +, −    | Обратная достижимость                        |
| ...      | −, +    | Симметрично со сменой знака управления        |

Вместе они покрывают **полную границу** прямого и обратного достижимых множеств двойного интегратора в пространстве состояний `(x, v)`.

| Русский                         | English                          |

| Достижимое множество            | Reachable set / Attainable set   |

| Кривая переключения             | Switching curve                  |

| Момент переключения             | Switch time / switching instant  |

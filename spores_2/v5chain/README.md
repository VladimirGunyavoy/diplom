# Player Zoom - Песочница для работы с камерой и зумом

Отдельный модуль для экспериментов с камерой, зумом и базовым управлением в Ursina.

## 📁 Структура

```
player_zoom/
├── assets/
│   └── arrow.obj             # 3D модель для осей координат
├── src/
│   ├── __init__.py           # Инициализация модуля
│   ├── scalable.py           # Базовые классы: Scalable, ScalableFloor
│   ├── frame.py              # Координатная система (оси X, Y, Z)
│   ├── scene_setup.py        # Плеер с расширенным управлением
│   ├── zoom_manager.py       # Управление масштабированием сцены
│   ├── window_manager.py     # Управление окном и мониторами
│   ├── color_manager.py      # Управление цветами
│   ├── input_manager.py      # Централизованная обработка ввода
│   ├── update_manager.py     # Координация update() компонентов
│   ├── my_object.py          # Демонстрационный движущийся объект
│   └── watcher.py            # Автоматический перезапуск при изменении
├── llm/                      # Контекст для AI агентов (см. llm/README.md)
│   ├── context/              # Архитектура, код, зависимости
│   ├── state/                # Текущее состояние, план, проблемы
│   ├── history/              # История изменений и решений
│   └── tools/                # Вспомогательные скрипты
├── main.py                   # Точка входа с демонстрацией
├── run.py                    # Запуск с автоперезапуском (watcher)
└── README.md                 # Этот файл
```

## 🎯 Основные классы

### Scalable
Базовый класс для всех масштабируемых объектов в сцене.
- `ScalableFloor` - клетчатый пол
- `ScalableFrame` - элементы координатной системы

### Frame
Визуализация локальной системы координат:
- origin_cube (начало координат)
- x_axis, y_axis, z_axis (оси)

### SceneSetup
Настройка сцены и плеера:
- FirstPersonController с расширенным управлением
- Освещение (DirectionalLight, AmbientLight)
- Управление курсором (toggle_freeze)

### ZoomManager
Управление масштабированием:
- identify_invariant_point() - точка взгляда
- zoom_in/zoom_out() - масштабирование
- register_object() - регистрация объектов для масштабирования

### WindowManager
Управление окном:
- Поддержка разных мониторов (main, top, left, down)
- toggle_fullscreen() - полноэкранный режим

### ColorManager
Загрузка и управление цветами из JSON

### UIManager
Централизованное управление UI элементами

### InputManager
Обработка всего пользовательского ввода

## 🎮 Управление (main.py)

### Базовое управление
- **WASD** - движение
- **Mouse** - обзор
- **Space/Shift** - вверх/вниз
- **Alt** - освободить/захватить курсор
- **Escape** - выход

### Zoom
- **E** - zoom in
- **Q** - zoom out
- **R** - reset zoom

### Другое
- **1/2** - замедлить/ускорить движущийся объект
- **F11** - полноэкранный режим
- **H** - debug info

## 🚀 Запуск

### Обычный запуск
```bash
python main.py
```

### С автоматическим перезапуском (рекомендуется для разработки)
```bash
# Вариант 1: через run.py
python run.py

# Вариант 2: через watcher напрямую
python src/watcher.py
```

**Поведение watcher:**
- При нормальном выходе (код 0) - автоматически перезапускает main.py
- При ошибке (код != 0) - останавливается, нужно исправить и запустить вручную
- Ctrl+C - остановить watcher

## 🤖 LLM Context (для AI агентов)

Директория `llm/` содержит структурированный контекст проекта для передачи знаний между диалогами с AI агентами.

**Цель:** минимизировать размер контекста при сохранении адекватности информации.

**Для новых агентов:**
1. Читай `llm/AGENT_START.md` первым
2. Изучай `llm/context/start_prompt.md` для быстрого старта
3. Проверяй `llm/state/` для текущего состояния и плана

**Подробнее:** см. [`llm/README.md`](llm/README.md)

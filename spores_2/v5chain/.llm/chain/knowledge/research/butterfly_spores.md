# Споры-«бабочки»: нормальный сегмент × время × ВСЕ управления (идея пользователя 2026-10-02; hub-v5chain-research-8)
**Вопрос** (пользователь): спора = нормальное пространство как дополнение к «времени и управлениям», интегрировать его сразу всеми u
вперёд и назад — «бабочка с плотной серединой»; что это даёт и как строить. **Ответ:** строится через якобиан D = [∂Φ/∂t, ∂Φ/∂u];
перебора слоёв нет, обратная задача (точка → s, t, u) у ДИ — формулой; Беллман делается самой картой. ДИ: V/T* мед. 1.04, агент 1.05 (мед. 1.03), 1–1.5 переключения, в 7 раз меньше узлов, чем клетки v7.

## Конструкция (`explain_butterfly.py`, `figs/explain_butterfly.png`)
Φ(c; t, u) — из споры c с постоянным u время t. D = [∂Φ/∂t, ∂Φ/∂u₁..∂Φ/∂u_m] (n×(m+1)); нормальное пространство = ядро Dᵀ, проектор
P = I − D(DᵀD)⁻¹Dᵀ, размерность n − m − 1. Карта споры: y = Φ(c + N·s; t, u) — (n−m−1) + 1 + m = n координат.
- 4D плоский ДИ (x, y, vx, vy; u = ax, ay): ранг D = 3, n = (−w̄y, w̄x, w̄y t/2, −w̄x t/2), w̄ — средняя скорость дуги; при t→0
  n₀ = (−vy, vx, 0, 0) — сдвиг вбок от скорости. Проверка: n(SVD) = n(формула), Dᵀn = 0. Облако σ=.08 вокруг c: из точки 0%, из отрезка
  |s|≤.15 — 48% (остальное требует |a|>1 — физика). Обратная задача: s = (d×w)/(n₀×w), t = 2(d − s n₀)·w/|w|², a = Δv/t, w = v_c + v_y.
- Если первых производных мало (m+1 < n), недостающее дают скобки Ли 2-го порядка (дд: v·ω·t²/2; ДИ при v=0: u t²/2) — направления «тонкие» (∝τ²).
- Избыточная карта (сечение n−1 + все u): в точку ведёт m-мерное семейство ⇒ V(y) = min по семейству [t + V_сеч(s)] — Беллман внутри карты.

## Прототип ДИ (`reports/research/butterfly_di.py`; цель ±.1, квадрат ±2.5, τ .5, отрезок |s| ≤ .1 вдоль v (⟂ дрейфу (v,0)), m = 7 узлов)
Дуга с постоянным u из y в точку p отрезка единственна: t = 2(x_p − x_y)/(v_y + v_p), u = (v_p − v_y)/t (годна при 0 < t ≤ τ, |u| ≤ 1).
Беллман (Гаусс–Зейдель): V(узел) = min по спорам рядом и s [t + V_c(s)]; «узлы» — только в узлы (без интерполяции ⇒ V ≥ T*), «интерп» —
s по сетке 21, V_c линейно. Агент: «dt» — держать u шаг .06 и перепланировать; «дуга» — держать u всю дугу до отрезка. T* — только оценка.

- Грабли (исправлено): (1) отрезки спор цели торчат за коробку — V=0 только у узлов внутри; (2) v_y + v_p → 0 — деление; (3) последний узел

# Дерево → V → агент: что определяет качество жадного агента по V (research-34, 2026-11-11)
**Вопрос.** Почему жадный агент по V на графе обратного дерева где-то ≈ эталон (кар 4D, круг), а где-то +13…+39% (дрон 6D, маятник/ДИ4D на первом заходе)?
**Ответ одной фразой.** Качество задаёт ошибка интерполяции V̂(x) = min_k [V_k + KV·d_k] вне узлов: KV мал → V̂ оптимистична, KV велик → завышена, в 6D — шумная при любом KV; правило KV_auto (квантиль .9 локальной Липшица V по рёбрам графа) попадает в лучший KV свипа без подбора.

## Схема диагностики (одна строка, без нового агента)
Разложение: V(x0) (V̂ в старте, без lookahead) / T_ref на тех же стартах.
- ≈ 1 по медиане и узкий разброс → граф в порядке, потеря — в агенте (шаг решения, жадность) → глубина lookahead / beam.
- < 1 → V̂ оптимистична (KV мал) → агент тянется в «дыры» → поднять KV (маятник: .82–.88 при малом KV).
- > 1 → V̂ завышена (KV велик), агент липнет к узлам (дрон KV 6: 1.55).
- медиана ≈ 1, p90 широкий → V̂ шумная (дрон 6D KV 3: 1.07/1.22) — плотность/KV не лечат, нужен поиск.

## Отрицательные (не повторять)
- Плотность дерева в 6D: охват не меняет (60→65/100 при NB 6k→1M), качество +2% (w38).
- V̂ первого порядка как min по линейным экстраполяциям (моё G5): при VI самосогласованно схлопывает V до ~.06 T — min по экстраполяциям оптимистичен; если пробовать — взвешенное среднее, не min.
- Гистерезис (держать u при ΔV ≥ −ε) на агенте дерева статик-кара вредит (50k: 24/32, мед 1.35; без — 30–32/32, 1.055; w39); на динамике — только после проверки на всех стартах подбора (b24).
- SLSQP-дожим плана жадного агента дрона: 1.309 → 1.234 — ошибка в топологии, не в моментах.

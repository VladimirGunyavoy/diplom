# lit_bangbang_cost — bang-bang у дифдрайва и обобщённая цена (заказ hub-research-7; hub-searcher-1, 2026-10-02)
Вопрос: (1) дифдрайв, быстродействие, |v_l|,|v_r|≤1 (= ромб |v|+|ω|≤1): строго bang-bang или есть внутренние управления? (2) цена T+ρ∫|u|² / T+ρ∫|u|: вид оптимального u для DI, маятника, дифдрайва.
Библиотека L1–L3 понята как уровни надёжности (L1 — прочитан текст источника, L2 — прочитана часть/аннотация, L3 — только сниппет поиска). Если имелось в виду другое — скажи.

## Ответ (кратко)
1. Дифдрайв, быстродействие: оптимум СТРОГО на вершинах коробки колёс (±1,±1) почти всюду — сингулярные интервалы тоже насыщены. Внутренних управлений нет. В координатах (v,ω) это вершины ромба (±1,0),(0,±1): либо прямо (⇑⇓), либо вращение на месте (↶↷). Остановка (0,0) — только тривиальная траектория.
2. Dubins/Reeds–Shepp: другое дело — сингулярная дуга u≡0 (прямая) лежит внутри допустимого [−1,1] (bang-singular-bang). У Balkcom–Mason при ограничении на колёса аналога нет: «прямо» = обе вершины (1,1).
3. Штраф ∫|u| (L1, «time-fuel»): bang-off-bang, управление принимает {+1,0,−1}; появляется нулевая зона (дрейф). Штраф ∫u² (L2): управление непрерывное и насыщенное u=−sat(p·g/(2ρ)) — рампы между насыщениями, вершины нужны только когда |costate|/(2ρ)≥1. Смесь λ|u|+½r u²: u=−sat(shrink(·)), непрерывное и с нулевой зоной.
4. Следствие для агента v7: при чистом T спектр не нужен ни у финиша, ни у кривой переключения (кроме вырождений типа Dubins). При ρ>0 L2 — нужен непрерывный спектр у финиша/на переключении (рампа), L1 — нужен ноль (дрейф) в промежутке.

## L1 (прочитано в тексте)
- Balkcom, Mason, IJRR 21(3):199–218, 2002, «Time optimal trajectories for bounded velocity differential drive vehicles» (rlab.cs.dartmouth.edu/publications/Balkcom2002a.pdf): 
  Thm 1 управляемость (↷⇑↷ достаёт любую цель); Thm 2 существование оптимума; Thm 3 (ПМП): ω1=−sign φ1, ω2=−sign φ2 почти всюду; Thm 4: общий корень φ1,φ2 ⇒ траектория тривиальна; Thm 5: на сингулярном интервале ω1=ω2 константы; Thm 7: интервалы трёх типов — дважды сингулярный (стоит), сингулярный (φ1 или φ2 ≡0: управления РАВНЫ и НАСЫЩЕНЫ ±1, прямо ⇑/⇓), generic (равные насыщенные — прямо; противоположные насыщенные — вращение). Итог: конечное число переключений, ≤5 действий (4 достаточно), траектория = прямые + повороты на месте. Надёжность: высокая.
- Balkcom, Kavathekar, Mason IJRR 2006 (омни): аналогично, дважды сингулярные экстремали не оптимальны (Thm 9) — см. lit_control_spectrum.md.
- Nagahara, Quevedo, Nešić, «Maximum-hands-off control and L1 optimality», arXiv:1307.8232: L1-оптимум — «bang-off-bang» (абстракт); Thm 5 — L1-оптимум = L0-оптимум (самое разреженное) при нормальности; §6 цена Σ(λ|u|+½r u²): Lemma 7 u*=−sat{S_{λ/r}(r⁻¹ gᵀp)} (S — shrinkage, ноль при |·|≤λ/r), Prop.8 — u* непрерывно по t, Prop.9 — предельно: λ→..., L1/L2 переходят в чистые L1/L2. Чистый L2 (λ=0) — частный случай леммы 7: u=−sat(r⁻¹gᵀp) (я применяю к λ=0, в тексте λ>0 — вывод очевиден из ПМП, но дословно не проверено).
- Sarkar, Patil, Kar, arXiv:2102.10831 (аннотация+§I–III): цена ∫(k+|u|)dt, |u|≤1, LTI — оптимум bang-off-bang, последовательности {+1,0,−1}; аналитически решается только DI и класс систем 2-го порядка (там же, ссылки [17],[10],[11]); для остальных — перебор кандидатных последовательностей + SDP. Цена T+ρ∫|u| = ρ∫(1/ρ+|u|): k=1/ρ.
- Kaya, arXiv:1901.00491 (аннотация): DI, min-energy + total variation, есть замкнутое решение; чистый минимум TV — кусочно-постоянное с одним переключением посередине. Побочное, но показывает вид решений DI при разных штрафах.

## L2 (частично)
- Caillau и др., arXiv:1504.06219 — при сингулярном стыке хаттеринг (см. lit_control_spectrum.md §П.4).

## L3 (сниппеты поиска, не проверено)
- DI time-fuel J=∫[λ+|u|]dt: u=+M при p2<−1, 0 при |p2|<1, −M при p2>1 (arXiv:2111.12225, Quasi time-fuel). Athans–Falb 1966 — классический источник. Выкладка p1'=0, p2'=−p1 ⇒ p2 линейна по t ⇒ не более 2–3 участков (+M/0/−M) — это МОЯ интерпретация, сверить.
- DI T+ρ∫u² (free T, |u|≤M): в литературе явного аналитического решения не нашёл. Из ПМП (моя выкладка, не источник): u=−sat(p2/(2ρ)), p2 линейна по t ⇒ «насыщение–рампа–насыщение», симметричная схема; нужна численная проверка (я не делал).
- Маятник: время-оптимальный подъём — bang-bang, возможна bang-singular-bang (MDPI «Optimal Erection of the Inverted Pendulum», doi:10.3390/app12168112 — страница дала 403, не прочитано; ResearchGate «Time Optimal Swing-Up Control of Single Pendulum» — только сниппет). Для маятника с ρ>0 источника не нашёл.
- Dubins: единственное сингулярное управление u≡0, bang-singular-bang (Boissonnat–Bui 1994; Sussmann–Tang 1991; arXiv:1704.04895 «Markov–Dubins path via optimal control» — сниппет).

## Не нашлось
- Аналитики T+ρ∫u² для DI, маятника, дифдрайва; сравнения T+ρ∫|u| для дифдрайва (ромб) — ни одной работы.
- Прямого результата «слабый штраф на u сохраняет bang-bang вне окрестности финиша» — нет, только структурные формулы выше.

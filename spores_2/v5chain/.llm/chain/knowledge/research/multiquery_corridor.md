# Многозапросность и коридор на адаптивном дереве (hub-research-2, 2026-09-30) — очередь research №2 и №4
**Вопрос:** (а) сколько спор на M запросов к одной цели при общем обратном дереве NB и прямом NF на запрос; (б) можно ли добрать
точность V/эталон ≈ 1.08 (проигрыш на квантах τ) до эталона без роста числа спор.
**Ответ:** точность даёт не число спор, а **коридор**: дерево выбирает только топологию (порядок слоёв), SLSQP — длительности.
Дифдрайв 3D, 30 запросов: **NB 1200 + NF 10 (1500 спор на все 30) → 30/30, T/эталон mean 1.004**; NF 50 → mean 1.000, max 1.004.
Без коридора V/эталон застревает на 1.07–1.09 при любом бюджете (до 22 800 спор).
## Схема (прототип `reports/research/corridor_nd.py`, общий для SysN)
1. Общее обратное дерево цели NB (строится раз на цель), прямое дерево NF на запрос (switch-first, как `adaptive_nd._tree`).
2. **Кандидаты:** каждая прямая спора × kn = 8 ближайших обратных → проигрыш последовательности слоёв. Вошёл в окно → score = t;
   **не вошёл → score = t + промах** (расстояние до окна). Промах не отбрасывать: топология верна, длительности поправит SLSQP.
3. Взять K = 5 лучших по score **разных** последовательностей (после слияния подряд одинаковых слоёв).
4. Каждую — SLSQP: min Σdt, dt ≥ 0, «конец в окне» (гладкие неравенства R² − x² − y² ≥ 0, Rθ² − Δθ² ≥ 0). Засчитывать
   **только допустимые** решения. Итог — минимум: реальная траектория (верхняя оценка), без квантов τ.
## Замеры (дифдрайв ромб, окно R = .25, Rθ = .26, τ = .25, ρ = .08, 30 случайных запросов из [−2, 2]² × S¹)
Эталон — `ref_window2` (min TGT в окно по выборке, TGTGT в окно, SLSQP с 40 стартами) = тоже верхняя оценка.
| вариант | покрытие | V/эталон mean / max |
|---|---|---|
| проигрыш (без коридора), NB 1200 + NF 50 / 200 / 600 | 30/30 | 1.088 / 1.34; 1.086 / 1.34; 1.073 / 1.28 |
| проигрыш, NB 4800 + NF 1 / 10 («только атлас») | 10/30; 22/30 | 1.08; 1.12 |
| коридор top-1, только вошедшие, NB 1200 + NF 200 | 30/30 | 1.013 / 1.282 (25/30 = 1.000) |
| коридор top-5, только вошедшие, NB 1200 / 4800 + NF 200 | 30/30 | 1.009 / 1.282 (29/30) |
| **коридор top-5 + промахи, NB 1200 + NF 200** | 30/30 | **1.000 / 1.0001 (30/30)** |
| коридор top-5 + промахи, NB 1200 + NF 50 / 10 | 30/30 | 1.000 / 1.004; 1.004 / 1.122 |
| коридор top-5 + промахи, NB 1200 / 4800 + NF 1 («только атлас») | допустимо 10/30; 20/30 | 1.025 / 1.20; 1.035 / 1.62 |
Время: обратное дерево 1200 — 0.6 с; SLSQP 5 топологий ≈ 1.5 с на запрос.
**Проверка честности** (`verify_corridor_dd.py`): 30 решений пересчитаны кинематикой эталонного модуля (`dd_rhombus_ref.pose`) —
0 невалидных, конец на границе окна (r = .25 ± 1e-9). Грабли (мои): первый прогон с промахами дал mean 0.933 — засчитывалась сумма
длительностей НЕдопустимого решения; исправлено (только допустимые).
**Почему выброс №25 (1.28) у «только вошедших»:** эталон — разворот → **задний ход** 2.0 → доворот. Обратные линии дерева идут через
Δθ = τ от одной затравки цели; на дистанции d боковой промах ≈ d·τ/2 = 0.28 > R ⇒ ни один проигрыш не входит в окно, топология
теряется. Рост NB не лечит (NB 4800 — то же 1.28). Кандидаты-промахи — лечат.
**Почему «только атлас» (NF = 1) покрывает мало:** у точки старта всего 1–4 разных топологии среди kn = 8 ближайших обратных спор;
прямое дерево NF = 10 даёт разнообразие префиксов → 30/30. Кроме того, та же причина — θ обратных линий квантован τ (гипотеза: затравки по окну цели,
`docking_nd.md` п.1, должны поднять покрытие без прямого дерева; не проверено).

## Маятник (u = .3): обратное дерево из равновесия вырождено
Затравка (π, 0): NB 400 → 7 спор (сдвиг за τ < клетки ρ, споры отбрасываются). Затравки на границе окна (16/32) → дерево полное,
проигрыш 8/8 (было 5/8, 7/8), V/Vfine mean .98 max 1.08 при NB = NF = 400 (`pend_back_seeds.py/json`). См. ISSUES.md.
**Коридор на маятнике** (`corridor_pend.py`, затравки по окну, NB = NF = 200, K = 5): **8/8 допустимо**, T/Vfine mean 0.988 (0.84…1.14),
проигрыш был 1.033 (0.84…1.26); T ≤ V проигрыша везде; концы проверены мелким rk4 (dt .001) — на границе окна. Vfine квантована по τ —
не точный эталон (T < Vfine у 5/8). Три обязательные правки (без них 5/8 и зависание): (1) **верхняя граница dt** в SLSQP
(≤ 1.5·Σdt₀ + 1) — иначе rk4 интегрирует огромные t; (2) **путь кандидата обрезать** в момент входа в окно / в точке наименьшего промаха;
(3) **ранжирование: K попаданий по t, затем K промахов** — единая шкала t + промах топит попадания (промах 1.4 = целое качание).
**Затравки по окну для дд — гипотеза опровергнута:** 12 × 3 = 36 затравок на границе окна, NF = 1 → допустимо 3/30 (NB 1200), 11/30 (NB 4800)
против 10/30 и 20/30 из центра: бюджет делится на 36 мелких деревьев. Правило: граница окна — только при вырожденном центре (маятник).

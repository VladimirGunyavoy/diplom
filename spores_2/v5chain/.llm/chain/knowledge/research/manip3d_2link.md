# 3D двузвенный манипулятор — постановка и эталон (research-21, 2026-10-07; слово пользователя 03:4x–03:5x)
**Вопрос:** новая система в конец порядка: поворот основания вокруг вертикали + плечо + локоть, 3 мотора, 6D, без гравитации и препятствий. Модель и эталон?
**Ответ:** точечные массы (локоть m1 = 5, конец m2 = 1; l1 = .5, l2 = 1) + диск основания I0 = .5; |τ_i| ≤ 1, |w_i| ≤ 3 (как у манипуляторов v6);
при w0 = 0, τ0 = 0 — РОВНО плоский 2-звенник v6 (a 2.5, b .5, d 1) с ИСПРАВЛЕННЫМ знаком Кориолиса (`ISSUES.md`). Эталон — OCP CasADi/IPOPT как `ref_6d.md`.

## Модель (`reports/research/r21/manip3d.py`: `f`, `flow` — API коридора v6, `energy`)
q0 — рыскание основания, q1 — тангаж плеча от горизонта, q2 — локоть относительно плеча. Радиусы масс от оси: r1 = l1 cos q1, r2 = r1 + l2 cos(q1 + q2).
L = ½ M00(q1, q2) w0² + ½ wpᵀ Mp(q2) wp, M00 = I0 + m1 r1² + m2 r2² (∈ [.5, 4]: рука вверх — рыскание ×8 быстрее, «фигуристка»), Mp — плоская матрица.
Уравнения: M00 ẇ0 + (∂1M00 w1 + ∂2M00 w2) w0 = τ0; Mp ẇp + Cp(wp) = τp + ½ ∂M00 w0² (вращение основания раскрывает руку к горизонту).
Перекрёстных членов в M нет (скорость в вертикальной плоскости ⟂ скорости рыскания) — связь только центробежная/кориолисова.
Проверка: τ = 0, 3 с, rk4 dt .001, 200 состояний — |ΔE|/E 7e-10; τ ≠ 0, 1 с — |ΔE − ∫τ·w| 1.3e-6; горизонтальная рука при вращении — равновесие (q1, q2 = 0 держатся).

## Запрос и эталон
Цель — покой в q* = 0 (рука вытянута горизонтально, рыскание 0): окно |q_i| < .3, |w_i| < .6 (как 6D v6, `check_corridor_manip6.py`); старты — тот же поток rng(0):
q ∈ [−π, π]³, w ∈ [−1, 1]³. Эталон `reports/research/r21/ref_m3d.py` (= `ref6d_ocp.py` с динамикой manip3d; CasADi-копия f совпала с numpy до 0.0),
multiple shooting N 50 M 4, мультистарт 4 затравки × ветви 2π, |w| ≤ 3 по пути; aida `~/spore_v5/r21/ref/` (16 запросов).
Слои — 8 вершин коробки моментов (релаксация: inf по вершинам = T* по коробке, `ref_6d.md`).

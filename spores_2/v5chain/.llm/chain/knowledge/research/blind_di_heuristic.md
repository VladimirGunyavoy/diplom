# «Слепая» DI-эвристика V для A* (hub-research-6, 2026-10-01; PLAN 0з п.6, 0з-7)
**Вопрос:** честная (без готового V) допустимая оценка времени до цели для поиска по графу клеток v7.
**Ответ:** h(x) = max_i max( T*_DI(Δq_i, ω_i; a_i,max), (|Δq_i| − R)/WM ), a_i,max ≥ |q̈_i| по модели — допустима, но слабая: маятник h/V медиана 0.41 (u=.3) / 0.59 (u=.5).
## Вывод
Каждая координата q_i с |q̈_i| ≤ a_i — DI с управлением a_i ⇒ время до цели ≥ T*_DI по этой координате (для Δq — кратчайшая ветвь круга, min по ±2π);
|q̇_i| ≤ WM ⇒ T ≥ |Δq_i|/WM. Максимум по i и по двум оценкам — тоже нижняя оценка. Маятник: a = g/l + u_max (|−sin θ + u| ≤ 1 + u).
Слабость — раскачка: a_max = 1.3 предполагает, что тяжесть помогает всегда; реально u=.3 требует нескольких качаний (V до 12 с, h ≈ 3–5).
## Проверка (`reports/research/blind_di_heur.py`, V — PendAtlas v6 144×121 τ .1, окно R .3, 4000 случ. точек |ω|≤3)
| u_max | h/V медиана | 10% / 90% | h > V |
|---|---|---|---|
| 0.3 | 0.41 | 0.24 / 0.70 | 0.3% — все в кольце 0.26–0.36 у окна цели (V ≤ 0.4) |
| 0.5 | 0.59 | 0.32 / 0.76 | 0.3% — там же |
Нарушения — от грубого учёта окна (T_DI до точки минус константа); честно: T_DI до диска окна или h = 0 в кольце 2R.
## Что нужно worker'у (v7)
Использовать как эвристику A* с весом (WH 1.5–3, как в 6D `tree_directed_6d.md`): при весе 2–2.5 оценка ≈ V в медиане, допустимость теряется — это нормально для поиска,
коридор/refine потом доводит T. Для манипуляторов a_i,max велико (Кориолис, |q̈| 30–100 при |w|≤3, `ref_6d.md`) ⇒ слагаемое DI почти ноль,
работает только |Δq|/WM — оценка ещё слабее (0.15–0.55, `ref_6d.md`). Евклид в нормированных координатах (нынешний v7) — не время, не допустим.

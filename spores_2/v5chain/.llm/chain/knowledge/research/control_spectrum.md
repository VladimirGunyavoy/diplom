# Спектр управлений: интерполяция между слоями (hub-research-6, 2026-10-01; литература — `lit_control_spectrum.md`, searcher-1)
**Вопрос** (PLAN «research: спектр управлений», (а)–(ж)): как агенту видеть ВСЕ u ∈ U, а не только вершины; что делать с вырожденными слоями; объединение/пересечение покрытий.
**Ответ одной фразой:** образ коробки U за шаг τ — почти аффинная (1-й порядок — параллелепипед) или квадратичная по u карта, её задают несколько слоёв:
для 1 канала хватает 3 слоёв (−1, 0, +1) — дальше u берётся непрерывно; в быстродействии это почти ничего не даёт (оптимум — bang-bang),
но у цели и на удержании решает всё: вершины дают «дребезг» с амплитудой ∝ u_max·τ, спектр держит цель (остаток в 100–1000 раз меньше, u в 10–100 раз глаже).

## Схема
- Система x' = f(x) + G(x)u (все наши системы аффинны по u). φ_τ(x,u) = x + τ(f+Gu) + τ²/2·(Df+Σu_i Dg_i)(f+Gu) + O(τ³).
  Слагаемые по u: линейное (параллелепипед), квадратичное u_i u_j·Dg_i g_j — **только если G зависит от x** (дифдрайв, манипуляторы; у DI и маятника G = const).
  Строго: ряд Чена–Флисса, ошибка усечения ≤ (C‖u‖_L1)^{M+1} (Beauchard–Le Borgne–Marbach 2023, Prop. 136 — через searcher).
- **Модели образа по слоям:** «каналы» Z(u) = φ(0) + Σu_i b_i + Σu_i² c_i (2m+1 слоёв: ±1 по каналу + дрейф, слово пользователя (д));
  полная квадратичная = каналы + m(m−1)/2 «диагональных» слоёв (e_i+e_j) — ловит перекрёстный член; тензорная 3^m — с запасом.
- **Выбор u** (ответ на (2) задачи): u* = argmin_{u∈U} V(Z(u)), V — цена (граф клеток), у цели — квадратичная (LQR P). 1 канал — поиск на отрезке,
  m каналов — QP по коробке (вблизи цели — точно LQR: «спектр + квадратичная V» = дискретный LQR; LQR-trees Tedrake 2010 — это и есть оно).
- (а)/(г) **Вырождение:** у вырожденного слоя (маятник θ = asin u_max, f+Gu_k = 0) трубка вдоль поля нулевой длины, но образ всей U не вырожден:
  отрезок длины 2u_max·τ по ω (в маятнике при θ=asin .3 ошибка «каналов» 5e-6 при τ = .8 — как в обычной точке). ⇒ Клетку строить по образу U
  (по полям f, g_1..g_m — их m+1, а не 2^m слоёв), не по одному слою. Замер (v7 `Cell`, маятник u=.3, слой +u, θ = asin .3 + dθ, ω=0): dθ = 0 — клетка
  нулевой площади (|f|=0, нормаль не определена), dθ = 1e-3/1e-2/.2 — длина вдоль потока 1e-4/1e-3/1.5e-2 при r=.07 — «иглы», покрытие там дорогое; размер — по теореме ball-box (растяжения τ по каналам, τ² по скобкам [f,g], [g_i,g_j]).
- (б) **Объединение/пересечение/разность:** двигаться (bang-bang) можно на ∪_k C_k; спектр (интерполяция по слоям) — только на ∩_k C_k (нужны все слои в точке);
  (в) достраивать — разность (∪ C) \ C_k для каждого недостающего слоя k. В v7 послойное покрытие = эта разность.
- (е) **Многоканальные:** дифдрайв (v,ω): каналов мало — дуги (u_v·u_ω) дают боковой сдвиг λ(1−λ)τ²/2 (это скобка [g_v,g_ω]); его нет в «каналах»,
  он есть в вершинах квадрата (вершины = дуги) или в диагональном слое ромба (v=ω=½). В ромбе вершины — прямая и разворот, дуги — на рёбрах.
- **Быстродействие:** внутреннее u оптимально лишь на сингулярных дугах (Balkcom et al. 2006 Thm 7 — для омни-платформы; у DI и маятника их нет:
  λ·g ≡ 0 ⇒ λ = 0). Внутреннее u на шаге τ ≈ переключение внутри шага (ШИМ/sum-up rounding, ошибка O(τ²) для DI) ⇒ коридор v6 с непрерывными dt_i
  уже реализует «спектр» во времени; спектр нужен там, где шаг τ фиксирован (агент по клеткам) и на удержании/стабилизации.

## Что нужно worker'у (v7)
(1) Слоёв на канал — 3 (−1, 0, +1; дрейф обязателен), для m ≥ 2 с G(x) — плюс диагональные (e_i+e_j); u — непрерывно argmin V(Z(u)) (1 канал — золотое сечение).
(2) Клетку цели делать LQR-клеткой «спектр + P» (не bang-bang): это и есть удержание. (3) Покрытие: спектр работает на ∩ слоёв — метрика v7
«доля точек, где все 2m+1 слоёв покрыты». (4) Не ждать выигрыша T в быстродействии: он даёт коридор с непрерывными dt (v6 уже).
Проверено (`field_model_q.py`, сверка с dpend 4e-15): «модель поля только по q» (у механики q̈ квадратично по ω, аффинно по u) — Тейлор-2 по q, |ω|≤3:
отн. ошибка ускорения 2 зв. ρ=.1/.2 — 3e-2/5e-2, 3 зв. — 8e-3/9e-2 ⇒ ~2e3 (4D) / 2e4–1.6e5 (6D) клеток в q — НЕ дешевле дерева v6 (NB 12k). Гипотеза отклонена.
Дешёвый путь к спектру: одна трубка клетки (дрейф или центр U) + чувствительности ∂φ_τ/∂u_i вариационными уравнениями (m столбцов) = столбец «лин» таблицы 1.

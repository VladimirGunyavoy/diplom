# Спектр у финиша / кривой переключения и обобщённая цена на клетках v7 (hub-research-7, 2026-10-02)
**Вопрос** (пользователь 2026-10-02): нужен ли спектр (промежуточные u) у финиша и при выходе на кривую переключения DI; при штрафе за управление
bang-bang не оптимален — насколько, и даёт ли спектр выигрыш?
**Ответ:** да, в обоих случаях. При чистом T спектр почти не меняет цену (1.042 → 1.023), зато убирает дребезг: переключений 3 → 1 (как у оптимума).
При J = ∫(1+ρu²)dt bang-bang проигрывает 12% (ρ=.5) и 46% (ρ=2); спектр из 11 значений держит 1.025–1.028 от оптимума ПМП.

## Постановка (`reports/research/v7_spore_spec.py`, `spec_vs_ocp.py`, `ref_di_cost.py`; aida ~/spore_v5/r7)
Клетки — по bang-слоям ±1 (схема `v7_spore_cells.md`, τ .4, r .1, 1209 клеток), они только сетка для V*. Беллман и агент берут u из набора U:
V*(узел) = min_{u∈U} [Δt(1+ρu²) + V*(φ_u(узел,Δt))]. У DI φ_u точен для любого u; в общем случае это образ U по слоям (`control_spectrum.md`).
Эталон при ρ>0 — ПМП: p₂ линейна по t ⇒ u* = sat(α+βt) (насыщение–рампа–насыщение, выкладка searcher'а `lit_bangbang_cost.md`, здесь проверена численно).
(α,β,T) — SLSQP из 60 стартовых точек с условием попадания в цель; при ρ→0 совпадает с T* (+0.1–0.4%). Агент ни разу не лучше эталона (доля <1 — 0).
Сетка HJB 361² как эталон не годится: завышает цену на ~1% (диффузия h²/dt), есть выбросы.

- **Дребезг при ρ=0 спектр НЕ снимает** (в отличие от DI): 37 скачков на траекторию, 48% — при E в ±5% от сепаратрисы E=1 (подход к верху по
  устойчивому многообразию), 36% — в последнюю секунду у цели. Гипотеза: V* имеет излом на многообразии ⇒ дискретный выбор чередует ±1 (скользящий режим).
  LQR-клетка у финиша (`pend_lqr_finish.py`, u=sat(−Kx) при xᵀPx≤c, 100 стартов): c = 0 / .05 / .2 / .5 → скачков всего 37 / 36.5 / 31.5 / **16**, у цели (|z|<.5)

  ε = 0 / .001 / .003 / .01 / .03 с → скачков 16 / **6** / 4 / 3 / 2, T 5.454 / 5.472 (+0.3%) / 5.505 (+0.9%) / 5.574 / 6.077 ⇒ рабочее ε ≈ .001–.003 с (≈ dt/30–dt/10).
- Сетка как абсолют завышает V на 3–10% (J агента/V сетки .90–.97) — сравнивать только отношения.

- Маятник: {−1,0,1} = спектр ⇒ оптимум bang-off-bang подтверждён. DI: дрейф необходим, но мало — агент с шагом dt не попадает в моменты
  переключения, промежуточное u компенсирует (как при ρ=0). Вывод: в агенте всегда держать непрерывный набор u, даже где оптимум кусочно-постоянен.

## Что нужно worker'у
1. Агент v7: u выбирать из непрерывного набора, а не из вершин: argmin_u [dt·c(u) + V*(φ_u(q,dt))], φ_u — через образ U по слоям (−1, 0, +1, `control_spectrum.md`).
   При чистом T это снимает дребезг у кривой переключения и у финиша; при ρ>0 без этого проигрыш 12–46%.
2. Агенту — LQR-клетка у цели + гистерезис ε ≈ dt/30…dt/10 (маятник: скачков 37 → 6, T +4%).
3. Беллман V* — с тем же набором U (иначе V* — bang-bang цена и агент недооценивает рампы).
4. Пара опытов на каждой системе (слово пользователя): маятник, дифдрайв (для дд при чистом T оптимум строго bang-bang — Balkcom–Mason, `lit_bangbang_cost.md`;
   при ρ>0 — рампы), манипуляторы. Эталон для ρ>0 — OCP мультистарт (CasADi на aida `~/spore_v5/r5/pylib`).

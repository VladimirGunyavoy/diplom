# Движущиеся препятствия: прогноз гауссовым облаком поверх готового графа (hub-v5chain-research-29, 2026-11-11; идея — пользователь)
**Вопрос.** Как вести агента спор среди дисков, которые движутся, если граф (атлас + V) построен заранее и закон движения агенту неизвестен?
**Ответ одной фразой (схема, НЕ проверена — гипотеза до замеров ENV3).** Граф без дисков строится один раз; каждый шаг агент по наблюдению (положение, скорость диска)
строит прогноз «среднее + облако, растущее как τ^1.5», и выбирает управление по V графа с ограничением на вероятность встречи вдоль своего ближайшего пути.

## Что в симуляции (journal-2026 `safe_car_goal_dynamic.py`; агенту НЕ сообщается — слово пользователя)
Диск r .70, центр = база + (A_x sin(Ωt + φ), A_y cos(.73Ωt + 1.7φ)), A = .42·(1, .65), Ω = 2π/(180·.08 с) = .436 рад/с. Отсюда (арифметика, не замер):
скорость диска ≤ A_xΩ = .18 м/с (машинка — до 2 м/с), ускорение ≤ A_xΩ² = .080 м/с², СКО ускорения по x .057, по y .020 м/с². Размах 2A = .84 м ≈ радиус диска.
Вывод: диски медленные; за время эпизода (~5 с) диск смещается на величину порядка своего радиуса — «снимок сейчас» плох на горизонте > 2 с, прогноз по скорости полезен.

## Модель агента (слово пользователя: случайное блуждание с гауссовым ускорением)
p̈ = ξ, ξ — белый гауссов шум интенсивности q по каждой оси. Наблюдаем p₀ и w₀ (разность двух последних положений / dt). Прогноз на τ вперёд:
среднее m(τ) = p₀ + w₀τ; дисперсия по оси σ²(τ) = σ₀² + qτ³/3 (стандартный результат для интегратора белого ускорения). σ₀ — ошибка наблюдения (у нас 0).
Калибровка q — по самим наблюдениям, без знания закона: q = 3·E[(p(t+τ) − p(t) − w(t)τ)²]/τ³ по скользящему окну прошлых шагов (старт — q₀ с запасом).
Прикидка для их синусоиды: ошибка прогноза по скорости ≈ ½aτ² ⇒ при τ = 2 с ~.11 м ⇒ q ≈ .005 м²/с³ (оценка; замерить в ENV3 п.1).
Ограничение облака: σ(τ) ≤ σ_max (иначе на дальнем горизонте облако закрывает всё поле — агент «замерзает»); горизонт прогноза H = 2–3 с.

## Вероятность занятости точки графа
Точка x, время прихода τ. P(x, τ) = P(|x − p(τ)| ≤ R), p ~ N(m(τ), σ²(τ)I). Точно — нецентральный χ² с 2 степенями; для запрета достаточно границы:
P ≤ ε ⇐ |x − m(τ)| ≥ R + κσ(τ), κ = √(−2 ln ε) (ε .05 → 2.45; .01 → 3.03). То есть диск радиуса R, раздутый на κσ(τ) и сдвинутый по скорости.
Время прихода в узел: вдоль пути агента τ = время от текущего состояния (у узла пути — V(старт) − V(узел)).

## Две схемы использования графа
**А (первой, дешёвая): граф как дальняя цена, облако — ограничение на ближнем горизонте.** Каждый шаг (или каждые k шагов): из текущего состояния кандидаты —
«слой u на время s, дальше жадно по V₀» для всех слоёв u и s из сетки (как LOOK/commit у агента) + текущий план; каждый прокатить на H; риск R = max_τ P(x(τ), τ);
выбрать min [время до конца горизонта + V₀(x(H))] среди кандидатов с R ≤ ε; нет таких — min R (уход). V₀ — атлас carfree, перестраивать ничего не нужно.
**Б (буквально по слову пользователя): пометка узлов и локальный пересчёт V.** В узлах в радиусе D от дисков: вероятность p_узла(τ_узла), ребро в узел с p > ε запрещено,
иначе цена Δt − λ ln(1 − p); V пересчитывается только в затронутой области (solve по вёдрам от её границы, `solve_bucket.md`). τ_узла — по текущей V от агента.
Дороже (пересчёт каждый шаг), зато обход выбирается глобально (какой стороной объезжать). Делать после А, если А застревает на выборе стороны.

## Проверка (ENV3, worker-b14)
1. Замер ошибки прогноза на их траекториях дисков: СКО при τ = .5/1/2/3 с для «снимка», «по скорости», и покрытие облака (доля попаданий факта в κσ) — калибровка q.
2. Агенты на 20 стартах × фазы (fixed и random): (0) carfree без учёта дисков; (1) снимок: диски стоят где видны, R + запас; (2) по скорости без облака; (3) схема А;
   (4) ясновидец OCP. Метрики: касания (доля эпизодов и глубина), T/T_ясновидца, мс на шаг. Свип ε ∈ {.2, .05, .01} и H ∈ {1, 2, 3} с — по одному прогону.
3. Стресс: амплитуда ×2 и период /2 (диски быстрее) — где облако начинает «замораживать».
## Риски (заранее)

у нас — непрерывно. Нулевого риска схема не обещает: ε — параметр.

# Точки поперёк клетки по гессиану vs равномерно (DI) — hub-research-1, 2026-09-29
**Вопрос:** при одинаковом числе точек N на сечении клетки даёт ли расстановка по гессиану V (source_doc §4) меньшую ошибку V?
**Ответ:** да, в ~96% сечений; выигрыш растёт с N: средняя ошибка −15% (N=3) … −48…−54% (N=9), максимальная −6% … −45%.
При равномерных точках ошибка убывает медленно (излом/корень V доминирует), при гессиане — почти вдвое на удвоение N.
**Схема:** 200 спор U[−2,2]², сечение ⟂ полю u=+1 длиной 2r; V = T* (оракул); кусочно-линейная интерполяция по N точкам, ошибка — max
по 2001 точке; расстановка — равнораспределение ρ = √(|V''| + 1e−3·max|V''|) (оптимум L∞ для линейной интерполяции).
**Проверка:** `reports/research/di_hessian_density.py` (+`.json`).
| r | N | равномерно mean / max | по гессиану mean / max | гессиан лучше |
|---|---|---|---|---|
| 0.2 | 3 | 0.051 / 0.514 | 0.043 / 0.485 | 97% |
| 0.2 | 5 | 0.034 / 0.381 | 0.023 / 0.296 | 96% |
| 0.2 | 9 | 0.026 / 0.266 | 0.012 / 0.146 | 96.5% |
| 0.5 | 5 | 0.097 / 0.601 | 0.068 / 0.483 | 97.5% |
| 0.5 | 9 | 0.065 / 0.416 | 0.034 / 0.258 | 98.5% |
**Оговорка:** гессиан — оракул (мелкая сетка). В коде его придётся оценивать по самим точкам клетки (2n+1 → только диагональ) —
выигрыш будет меньше; итеративно: равномерно → оценить V'' → переставить. Max ошибки 0.15–0.5 — у излома/цели (там клетка цели и min двух Q).
**Что нужно worker:** при N ≥ 5 точек на сечение — расставлять по |V''| (итеративно), это дешёвый выигрыш ×1.5–2 по средней ошибке.

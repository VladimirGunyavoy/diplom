## Было в прошлых, нет в v8, стоит вернуть (по приоритету для ДИ; число — основание, файл — источник)
1. **Финиш стрельбой у цели** (≤2–3 дуги, SLSQP). v7 grow3: T/refbox 1.0153→**1.004** (max 1.010) с финишем VF5; spore_v/ДИ: у цели +0.01 с. В v8 причина «не доходят» — дребезг у круга (101–120 переключений, слой u=0 лечит частично). `v8/src/algo/finish_gen.py` уже есть, к агенту не подключён — `plan_archive.md` п.17б/22, `v7/reports/grow3/results.md`.
2. **Точное переключение через сопряжённую p / ноль σ(t)** вместо argmin по шагу: DI аналитически t_s=p_v0/p_x и T/T*=1; маятник 1 переключение вместо ~39, T −6% — `exact_switch.md`. v8 look: 11–31 переключений на старт.
3. **Адаптивное число узлов поперёк клетки (MADAPT 5→9→17→33) + подклетки MROW** — у v8 M=3 фиксировано, адаптивен только шаг ВДОЛЬ. Маятник: MADAPT .001 → 1.0089 при 237 клетках против ~686; MROW узлов −52…60% при T 1.040 — `nf_curved_ends.md` п.5, `grow_cells2d.py:375–448`. Индикатор там геометрический (отклонение торца), не по V (см. past_subcells, lit_adaptive_mesh).
4. **CUTR — стена на разрыве V бисекцией по метке траектории агента**: −20…27% спор при T/эт 1.028 (против 1.023), маятник; OWN+CUTR — 1059–1155 спор — `cut_walls.md`. Для v8: решение проблемы «излом внутри ячейки» (п.46: размах V>.5 у 76% ячеек) — узел/стена НА изломе, а не дробление.
5. **Беллман-min / «min двух интерполянтов» (АТЛАС §7)**: v5chain mean .0073→.0050, max .278→.159 без новых узлов (×2 запросов) — `reports/atlas_double_integrator.md` §2. В v8 есть maxv (оценка сверху), но min двух не реализован; `pause_2026-10-08.md` п.2.
6. **LOOK-прокатка агента**: маятник L5 1.015, L10 1.012, L20 **1.008**, цена агента +130 с (LOOK 0 быстрее запроса ×55 — слово польз. «время важнее процентов») — `cut_walls.md` §LOOK. v8 look = 1 шаг Беллмана (83.5% → при M=5 85%).
7. **dt_edge = шаг агента + Эрмит-locate**: spore_v/ДИ T/T* 1.151→**1.044**, узлов находят клетку 57→99.9% — `spore_v_di.md`, STATUS w13.
8. **PRUNE / BIDIR под запрос** (growNq): .31–.58 клеток полного при том же T — `v7/reports/growNq/results.md`. Нужно для nD, не для ДИ 2D.
9. **Коридор SLSQP/IPOPT по топологиям** (v6 `corridor_nd.refine`, v7 `refine.py`): nD 30/30 T/ref 1.004; g=2 ×1.0016 — для ДИ 2D избыточно, для маятника/nD нужен; в v8 нет.
10. **Цепочки с выравниванием (H2)**: споры = выходы потока без округления (σ=.01 ⇒ +28%). В v8 соблюдается по построению (клетки растут из траекторий); отдельно не проверялось.

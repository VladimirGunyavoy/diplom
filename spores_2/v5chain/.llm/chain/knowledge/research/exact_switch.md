# Точный момент переключения вместо размазывания спектром (hub-research-7 → hub-v5chain-research-8, 2026-10-02)
**Вопрос** (пользователь): не размазывать переключение промежуточными u, а находить его момент точно/аналитически.
**Ответ:** переключение — СОБЫТИЕ на дуге, а не выбор слоя на каждом шаге: ноль функции переключения σ(t) = p(t)·(f_k − f_k') по сопряжённой
переменной p (из ∇V один раз, дальше уравнение ṗ = −f_xᵀp) + точный финиш стрельбой из ≤2 дуг в цель + пересчёт финиша (обратная связь).
Маятник: 1 переключение вместо ~40, T на 6% лучше агента «по шагам». Нужна обратная связь: подход к верху — устойчивое многообразие седла.

## Почему прежний критерий хрупок (`exact_switch_di.py`, hub-research-7)
«Заглянуть на h»: D = [h+V(φ_k)] − [h+V(φ_k')]. У кривой переключения p·Δf → 0 линейно (ПМП), D = O(h²) ⇒ шум V сильнее сигнала; меньше h — хуже
(DI до ×4, 15–39 переключений). Ноль σ(t) вдоль дуги, наоборот, трансверсален (σ̇ = −p_φ ≠ 0 у маятника, −p_x у DI) ⇒ корень резкий.
DI аналитически: вдоль дуги p_x = const, p_v = p_v0 − p_x t ⇒ t_s = p_v0/p_x; финиш из 2 дуг — формула T* ⇒ T/T* = 1, одно переключение, цель-точка.

## Споры-характеристики: кривые переключения без V (`pend_characteristics.py`, `figs/pend_char_switch.png`)
Пары (x, p) назад от границы цели (p = ν·нормаль, на углах веер, ν из H = 0), u = −UM·sign p_ω; 5012 характеристик × 14 с, 8 с счёта.
Точки нулей p_ω ложатся РОВНО на границы слоёв сетки V (главная кривая через цель, кривые раскачки у φ ≈ ±1.8, ±2.55) ⇒ кривые переключения
находятся без V и без диффузии — это и есть «сечение клетки = поверхность переключения». Другие границы слоёв сетки — вероятно, линии
рассеивания (две оптимальные траектории расходятся, V с изломом; гипотеза по картинке). V как min по характеристикам пока плохо: покрыто

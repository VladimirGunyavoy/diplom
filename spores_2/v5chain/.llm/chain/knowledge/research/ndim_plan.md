# n-мерные системы для v6: что значит «DI с ускорениями» (hub-research-1, 2026-09-29, решение research)
**Вопрос:** пользователь: «n-мерные — тот же DI, но с ускорениями». Трактовки: тройной интегратор (управляем рывком) или DI в 2D/3D.
**Ответ (решение research):** брать **обе**, в таком порядке — они проверяют разное:
1. **Тройной интегратор** ẋ = v, v̇ = a, ȧ = j, |j| ≤ 1 — 3D, одно управление, bang-bang с ≤ 2 переключениями (порядок системы − 1,
   теорема Фельдбаума для линейных систем с вещественными собственными числами). Проверяет рост размерности при той же структуре слоёв
   (2 слоя), сечение клетки — 2D-площадка (2n+1 = 7 точек V). Эталон — численно (оптимизация 2 моментов переключения, Kaya–Noakes),
   замкнутая формула громоздкая — не выводить.
2. **DI на плоскости с круговым ограничением** ẍ = a, |a|₂ ≤ 1 — 4D. Здесь вершин у множества управлений **бесконечно** (окружность):
   слои = K направлений (вписанный K-угольник). Проверяет главное допущение метода — конечный набор экстремалей. Оценка потерь (вывод):
   вписанный K-угольник гарантирует ускорение ≥ cos(π/K) в любом направлении, время DI ∝ 1/√a ⇒ худший случай замедления
   1/√cos(π/K): K = 4 / 6 / 8 / 12 / 16 → +18.9% / +7.5% / +4.0% / +1.8% / +1.0%. Эталон: без клеток — задача решается сдвигом
   сопряжённых (направление u поворачивается непрерывно), численно — прямой оптимизацией.
   (Коробочное ограничение |a_i| ≤ 1 распадается на независимые 1D-DI — неинтересно, только как проверка кода.)
3. Далее — динамический манипулятор 4D/6D (`manipulator_plan.md`).
**Проверка:** оценка K-угольника — арифметика (выше); теорема о числе переключений — классика (Фельдбаум; Понтрягин и др.), не проверял
по источнику дословно.

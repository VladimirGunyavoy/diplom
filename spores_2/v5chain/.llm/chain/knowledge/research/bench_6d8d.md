- Вывод для цели «споры быстрее всех»: на этих средах НЕ показано; заявимо «качество = эталон, одна заготовка на цель»; выигрыш на запрос нужен от ускорения запроса (SLSQP-refine — основной расход) — задача для линии скорости.

## SPD6 — ускорение запроса коридора v6 (w27, 2026-10-13 06:3x)
Профиль (m3d, 1 запрос 79 с): 71 с — скалярный RK4 в SLSQP (refine) с конечными разностями (~6600 вычислений ограничения × n сегментов). Что сделано (код `bench/refine_ca.py`, `bench/tree_fast.py`, включение env `CAREF=1 TREEFAST=1 BATCHFAST=1` в `spores_6d.py`; нужен `PYTHONPATH=~/spore_v5/r5/pylib` для casadi на aida):
1. refine через CasADi/IPOPT (точные производные, RK4 10 шагов/сегмент, |w|≤3 по каждому шагу для wlim; решение перепроверяется точным потоком коридора; солверы по n сегментов собираются заранее, 4–5 с «заготовки»); если запрос без пути — повтор штатным SLSQP (CAFB).
2. `_tree` без лишнего потока полудуги (препятствий нет) + все 8 слоёв одним вызовом скомпилированной (gcc) casadi-функции map; пакетный поток стыковки (`flb_*.so`, map(64)) — выигрыш мал.

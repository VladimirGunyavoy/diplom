# lit_flow_normal_sections — нормальные (гипер)плоскости к потоку (searcher-2, 2026-10-07)
Заказ: research-24. Полный обзор: `~/claude-work/library/reviews/2026-10_flow_normal_sections.md` (карточки в `library/sources/`).
**Вопрос:** как правильно строить многомерные сечения ⟂ потоку (шаг по базису → пересчёт → ...), если f⊥ неинтегрируемо.
**Ответ:** единого метода не найдено. Факты: f⊥ (n=3) интегрируемо ⇔ ω∧dω=0; дифдрайв: ω∧dω=−v² dx∧dy∧dθ ≠ 0 (проверено вручную, совпадает с выкладкой заказчика) → контактное, ⟂-поверхностей нет; перенос нормального базиса с минимальным кручением — RMF; однозначное по зерну — СР-экспонента от ковектора; в cell mapping / LQR-trees сечение ⟂ f не выбирают.

## Применимо к нам
- Дифдрайв: контактность → «честного» ⟂-сечения нет, результат зависит от пути; RMF-перенос даёт воспроизводимый (но не единственный) базис вдоль выбранной кривой.
- 4D манипулятор: специальных источников нет.
## Не нашлось / не проверено
Метод минимизации неортогональности; n-D RMF с оценкой ошибки; формула голономии для общего f⊥; критерий для n≥4. Не открыты: Lee (гл. 19), Montgomery «Tour», Arnold ODE, Winfree 1974, Guckenheimer 1975, Osinga–Moehlis, Detrixhe 2016 (только аннотации).

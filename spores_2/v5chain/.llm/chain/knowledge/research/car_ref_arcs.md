# Статик кар: на каких ограничениях идёт эталон (research-30, 2026-11-11; задача senior-1)
**Вопрос.** Какую долю времени эталон OCP (r21, 20 стартов) проводит на краю дисков, на v = v_max, на |a| = AM, |ω| = WM — вход для «граничной клетки».
**Ответ одной фразой.** v = v_max — 45% времени (дуга на фазовом ограничении с a = .625·2 = 1.25, не ±AM); край дисков — ~2%; |ω| = WM — ~3%, ω почти всегда 0.

## Замер (`reports/research/r30/car_ref_edges.py`, управления aida 1 `~/spore_v5/r21/ref_car_N80/car_q*.npy`, прокатка rk4 dt .002; N40 — то же)
| величина (медиана / среднее по 20 стартам) | N80 |
|---|---|
| доля t с зазором до диска < 1 см | .013 / .023 (max .073; мин. зазор у 14/20 стартов < 2 см) |
| доля t с v > v_max − .01 | .454 / .453 |
| доля t с |a| = AM | .550 / .549 (разгон до v_max; торможения нет) |
| доля отрезков |ω| < .05 / промежуточн. / = WM | .90 / .07 / .03 |
T прокатки = car_ref20 (16/20 точно; у 4 стартов N40 хуже N80 — car_ref20 = лучший); конец в цели с точностью ≤ 6 мм (rk4 OCP грубее).

## Вывод
- Эталон = «разгон a = AM до v = 2, дальше ДЕРЖАТЬ v = 2 (a = 1.25)», руль — bang–off–bang с короткими дугами WM. Касание дисков — короткие эпизоды.
- **Гипотеза (не проверена):** в `growCar` слои a ∈ {±1.5} (`US`, стр. 42); при v = 2 слой a = +1.5 даёт v̇ = .25 > 0 → выход из поля (v ≤ VHI — граница поля),
  удержать v_max атлас не может: только пилой ±1.5 или ниже v_max. Это может быть частью разрыва кара (T/T_ref 1.08) — проверить слоем «удержание v_max»
  (a = KV·VHI, ω ∈ {0, ±WM}) или клипом v в потоке. Оценка потерь пилой — не делалась.
- Для «граничной клетки» (диск, |ω| = WM): по времени эталона это ~2% и ~3% — малый резерв; v_max — главный.

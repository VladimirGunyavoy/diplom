## Модель (у них дискретная, dt .08, Эйлер; для атласа — непрерывная форма)
Состояние 4D (x, y, θ, v); управление (a, ω): |a| ≤ 1.5, |ω| ≤ 1.8 (ω — прямо скорость рыскания, как у дифдрайва, но v — состояние с ускорением).
ẋ = v cos θ, ẏ = v sin θ, θ̇ = ω, v̇ = a − k v, **k = .625** (решение research-21: явный Эйлер с k .625 = их карта v ← .95 v + .08 a ровно; затухание за шаг .9512 против .95 — 0.1%; k .641 дал бы вход .078 a). Порядок их шага: θ → v → позиция по новым θ, v; v ∈ [−1, 2] (клип: назад до −.5·max_speed).
Поле |x|, |y| ≤ 5 (выход — нарушение); 3 диска-препятствия r = .70: (0, .2), (1.8, 1.5), (−1.6, 2.3). Цель — круг (4, 3.6) r .45, θ и v любые.
Старты у них: x, y ∈ [−4.25, 0] × [−4.25, .3], ≥ .2 от дисков, v = 0, θ на цель + N(0, .25).
## Их цифры и грабли (ответ research журнального проекта)
Эталона оптимального времени у них НЕТ (безопасный RL без штрафа за время; MPC — random shooting без замеров времени). Обученная политика: 66–70 шагов = 5.3–5.6 с в среднем по стартам,
но 1–20% эпизодов с касанием диска (`runs/aida/2026-10-06_check_mseed_l2_static/seed20*/eval_history.jsonl`) — ориентир «сверху», не эталон.
Грабли: робот — точка; проверки только в отсчётах .08 с (между ними можно «срезать» край диска — у нас проверять непрерывно/мелким шагом); нарушение не завершает эпизод;
диск (1.8, 1.5) почти на прямой старт → цель ⇒ два класса обхода (эталон — мультистарт по обеим сторонам).
## Для spore
Задача — минимум времени до круга цели без касания дисков/стены. Слои: 4 вершины (±1.5, ±1.8) (+ a = 0 / ω = 0 по спектру). Эталон — OCP CasADi (как `r21/ref_m3d.py`)
с ограничениями дисков вдоль пути, мультистарт по сторонам обхода. Дешёвая нижняя оценка: разгон по прямой с v ≤ 2 (T ≥ дистанция / 2 + разгон).
Цель — 2D-множество (θ, v свободны) ⇒ V от цели растекается легче, чем у DI 4D с точечной целью.

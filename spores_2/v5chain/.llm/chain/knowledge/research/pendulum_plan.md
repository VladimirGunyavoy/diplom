# Маятник для v6 — прикидка «на бумаге» (hub-research-1, 2026-09-29)
**Вопрос:** что меняется для атласа v6 при переходе DI → маятник, какие параметры и эталон брать?
**Ответ:** модель как в v4_circle (θ̈ = −sin θ + u, g/l = 1, m·l² = 1, θ=0 — низ), **u_max = 0.3 или 0.5** (слабый мотор ⇒ раскачка
с несколькими переключениями — первый тест коридора с > 1 переключением); цель сначала низ (0, 0), потом верх (π, 0) с клеткой-LQR.
**Отличия от DI:**
1. θ периодична — атлас на цилиндре: соседи и интерполяция по θ через 2π; споры не дублировать на θ = ±π.
2. Нормировка (§7): L = π для θ, собственное время T = √(l/g) = 1 ⇒ θ/π, θ̇/π.
3. Поле поворачивается вдоль орбит (угол — не критерий, подтверждение §3). Растяжение только у седла: у слоя u седло sin θ* = u
   (верхнее), показатель λ = (1 − u²)^¼: 0.98 / 0.93 / 0.78 при u = 0.3 / 0.5 / 0.8 ⇒ длина клетки у сепаратрисы τ ≤ ln ρ_max / λ
   (ρ_max = 3: τ ≤ 1.1–1.4); вдали от седла клетки могут быть длинными. Тест «Phase-Atlas» §5: медиана длительности клеток в полосе
   |E − E_sep| < 0.05·E_sep меньше, чем вне её (E = θ̇²/2 − cos θ).
4. Равновесия слоя (F_k = 0 при θ̇ = 0, sin θ = u_k): клетку слоя k там не строить, дыру закрывают другие слои (§9 PA).
5. Цель вверху неустойчива ⇒ клетка цели = LQR по линеаризации, её радиус — оценка области притяжения при |u| ≤ u_max (мала при
   u_max = 0.3); цель внизу — клетка цели почти свободная (устойчивое равновесие + трение/тормоз).
**Проверка (малая, численно):** энергонакачка bang-bang u = u_max·sign(θ̇) из покоя внизу до E = 1 (энергия верха):
u_max = 0.3 / 0.5 / 0.8 — 11.1 / 6.0 / 4.0 с, смен знака 3 / 2 / 1 (эвристика, не оптимум; порядок числа переключений).
**Эталона в формулах нет.** Предлагается: (а) мелкая сетка V (полулагранжево, h = 0.02–0.05, τ ≈ √h, `solve_V`-подобно) — на aida;
(б) коридор + оптимизатор моментов (Kaya–Noakes) из нескольких стартов; сверять (а) и (б) между собой.
**Что нужно worker (когда дойдёт до маятника):** модель из v4_circle; u_max = 0.5 первым (2 смены), затем 0.3; цель — низ, потом верх;
τ ≈ √h как в DI; эталон — мелкая сетка на aida; тест растяжения у сепаратрисы.

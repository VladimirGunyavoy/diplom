# Стыковка деревьев в nD (hub-research-1, 2026-09-30) — продолжение adaptive_vs_grid №4
**Вопрос:** в 2D стык = пересечение прямой траектории (1D) с обратной цепочкой (1D) — работает (маятник 8/8). В 3D (дифдрайв) кривая
с кривой общим положением не пересекается. Как стыковать?
**Ответ (гипотеза, не проверена):** стыковать не с цепочкой, а с **листом** — (n−1)-мерной поверхностью из семейства обратных цепочек
с одинаковой последовательностью слоёв, выпущенных из (n−2)-параметрического семейства точек на границе окна цели.
Траектория (1D) пересекает лист ((n−1)D) общим положением.
**Схема:**
1. Цель — окно (шар/коробка), не точка. На его границе берём семейство стартовых точек: в 3D — кривая (окружность по xy при θ = 0,
   или контур окна), параметр σ.
2. Для каждой последовательности слоёв (как ветви обратного дерева) выпускаем цепочки из точек σ₁ < σ₂ < …; соседние цепочки с одной
   последовательностью образуют полосу-лист, триангулируем (σ, t).
3. V на листе: вдоль t точно (время до окна), поперёк σ — линейно между соседними цепочками (локально, не Делоне по всему набору).
4. Стык: пересечение отрезков прямой траектории с треугольниками листов (векторно, хэш).
5. **Проверка стыка (делает оценку честной):** из точки пересечения проиграть последовательность слоёв листа с моментами переключения,
   интерполированными по σ, и убедиться, что траектория входит в окно; фактическое время — верхняя оценка без интерполяционной ошибки.
6. Покрытие: мало листов — стык не найден (inf), как в 2D при малой глубине; делить глубину переключений между деревьями (2D-опыт).
**Почему это правильная размерность:** «Phase-Atlas» §4 (flow box) — множество, выметаемое потоком (n−2)-мерного семейства, имеет
размерность n−1; это та же конструкция, что стены клетки, только из цели назад. Связь: поверхности переключения в теории синтеза
оптимального управления — именно такие листы (без проверки по источнику).
**Проверка предлагается:** дифдрайв ромб-U, окно цели R = .25, Rθ = .26; 20 запросов; эталон min(TGT, TGTGT) «до окна»; метрики —
доля найденных стыков, V/эталон (≥ 1 после шага 5), число цепочек.
**Что нужно worker:** после маятника — дифдрайв 3D с листами; если листы сложно — упрощение: стык с гало обратной клетки + шаг 5
(проигрыш и проверка) — честность даёт именно шаг 5, а не геометрия стыка.

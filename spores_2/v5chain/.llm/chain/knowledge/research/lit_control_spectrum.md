# lit_control_spectrum — непрерывный спектр управлений (заказ hub-research-6; звено hub-searcher-1, 2026-10-01)
Вопрос: чем заменить «вершины коробки U» на непрерывный образ U за время τ (x'=f+G(x)u, u∈коробка); что известно про оценку, воронки, примитивы, сингулярные дуги, квантование.
Метка: [П] = прочитано в тексте источника; [С] = только сниппет поиска, не проверено.

## Ответ (кратко)
1. Образ коробки за малое τ — в первом порядке аффинный по u ⇒ зонотоп (при m каналах — параллелепипед или его проекция), ошибка O(‖u‖²_L1)=O(τ²) при |u|≤1; 2-й порядок даёт скобки Ли [f,g_i],[g_i,g_j] — кривизна. Это математически строго (Chen–Fliess), но готовой «ошибка ≤ …» для нашего случая без констант нет — константы C зависят от аналитической нормы полей.
2. Воронки (LQR-trees): покрытие — лес воронок-эллипсоидов, новые сэмплы внутри уже покрытого отбрасываются; выбор ветки — по max запаса c(x,t,b). Прямая аналогия «слои = воронки», но воронка = область стабилизации вокруг траектории, а не образ U.
3. Примитивы: конечная библиотека даёт дискретное достижимое множество; непрерывность получают либо непрерывным параметром (длительности trim), либо lattice. Потеря оптимальности от конечного набора в литературе названа открытой (future work у Frazzoli).
4. Сингулярные дуги: в быстродействии оптимум лежит внутри U только на сингулярных дугах; для diff-drive/омни-платформ они есть, но «дважды сингулярные» никогда не оптимальны; при сингулярной дуге высшего порядка стыки с bang-дугами хаттерят (Fuller).
5. Квантование: sum-up rounding даёт бинарное управление, у которого интеграл отличается от непрерывного ≤ (M−1)Δt, а состояние — ≤ C·ε. Т.е. любое внутреннее u (непрерывный спектр) реализуется вершинами ШИМом с ошибкой O(Δt).

## Источники по пунктам
### П.1 Достижимые множества
- Beauchard, Le Borgne, Marbach, arXiv:2012.15653 (v4 2023), §6.1 Prop.136 [П]: для x'=f0+Σu_i f_i, аналитика, ‖u‖_L1≤η, t≤η:
  φ(x(t))=Σ_σ(∫u_σ)(f_σφ)(p); усечение по числу ненулевых букв ≤M даёт ошибку ≤(C‖u‖_L1)^{M+1} (ф.368). M=1 ⇒ аффинно по u, ошибка квадратична; M=2 ⇒ iterated integrals с [f_i,f_j]. Оценка (369): |∫u_σ|≤‖u‖^{n(σ)}/n(σ)! · t^{n0}/n0!. Надёжность: высокая (строгие доказательства), но η мал (η=r/(10‖f‖)). Для обычного Магнуса — контрпример сходимости (§6.2), использовать «interaction picture» (§6.3) или Chen–Fliess.
- Kawski, «Calculating the logarithm of the Chen–Fliess series» (mathweb.ucsd.edu/~helton/MTNSHISTORY/…/B115.pdf) [С]: правило для коэффициентов при скобках Ли в логарифме ряда (нелинейный Магнус).
- Althoff, «Reachability analysis of nonlinear systems with uncertain parameters using conservative linearization» (CDC 2008; mediatum.ub.tum.de/doc/1289370/385898.pdf) и «…conservative polynomialization and non-convex sets» (HSCC 2013, dl.acm.org/doi/10.1145/2461328.2461358) [С]: локальная линеаризация + остаток Лагранжа как интервал→зонотоп (консервативно, включает всё); полиномиальные зонотопы = аналог Taylor-моделей, закрывают 2-й порядок/невыпуклость. CORA — реализация (не проверял).
- Rieger, Wawryk, arXiv:2305.12727, §1 [П]: схемы Рунге–Кутты для достижимых множеств дают порядок ≤2 вообще, второй порядок требует очень сильных предположений; на практике 1-й порядок (Эйлер). Вывод: ждать от 2-го порядка по τ гарантий нельзя.
- Kurzhanski (эллипсоиды) — не искал/не проверено.

### П.2 Воронки
- Tedrake, Manchester, Tobenkin, Roberts, IJRR 2010 (groups.csail.mit.edu/robotics-center/public_papers/Tedrake10.pdf) [П]: §4 алгоритм: узел {x,u,S,K,ρ,родитель}, воронка J*(x,t)≤ρ(t) (эллипс), дерево растёт от цели, сэмплы внутри C_k отбрасываются (быстро из-за эллипсоидов); коннект — траекторная оптимизация с «final tree constraint» (ф.52); исполнение — выбор ветки argmax c=ρ_b(t)−(x−x_b)ᵀS_b(x−x_b) (ф.54–55). §3.4 — насыщение входа проверяется по 3^m комбинациям (насыщ./нет) — для нас важно: ограничения коробки в SOS есть, но экспоненциальны по m. §6 — «вероятностное покрытие».
- Majumdar–Tedrake funnel libraries — не открывал, [С/не проверено].
Применимо: критерий «точка уже покрыта» (отбрасывание) и выбор по запасу ρ−V — готовые идеи для перекрытия слоёв.

### П.3 Примитивы
- Frazzoli, Dahleh, Feron, IEEE T-RO 21(6) 2005, §III.C, §VI [П]: конечная библиотека ⇒ дискретное достижимое множество; чтобы получить непрерывное, вводят непрерывно параметризованные trim-примитивы (постоянные управления, относительные равновесия); оптимизация по длительностям примитивов — конечномерная гладкая невыпуклая (ф.13, Thm 6.3 о существовании). Потеря оптимальности от конечной библиотеки — прямо названа задачей на будущее (§VIII). Практика: сотни примитивов (625 в [13]).
- Pivtoraiko, Knepper, Kelly, JFR 26(3) 2009 [С]: control set = минимальное множество путей между соседними узлами решётки, найденных решением краевой задачи; эквивалентные классы путей убирают избыточность. Интерполяции управлений между примитивами не нашёл ни в одном источнике.
- Dispersion-minimizing primitives, arXiv:2103.14603 [С]: выбор примитивов по дисперсии (покрытие) — полезно для «сколько вершин/слоёв нужно», не читал.

### П.4 Сингулярные дуги
- Balkcom, Kavathekar (+Mason), «Time-optimal trajectories for an omni-directional vehicle», IJRR 2006 (cs.dartmouth.edu/~rlab/publications/Balkcom2006a.pdf) [П]: Thm 1 — v_i=−sign φ_i (bang-bang) пока φ_i≠0; λ0=|φ1|+|φ2|+|φ3| константа; Thm 7 — на сингулярном интервале v_i=0, v_j=−v_k=±1 (поступательное движение вдоль линии переключения) — то есть оптимум на ГРАНИ, не вершине; Thm 8–9 — дважды сингулярные экстремали (две компоненты в серединах) не оптимальны. Для diff-drive: Balkcom–Mason 2002 (в поиске, не открывал [С]).
- Kelley/обобщённое Лежандр–Клебш: (−1)^k ∂/∂u d^{2k}h/dt^{2k} ≤0 для сингулярной экстремали локального порядка k [С: сниппет поиска; Robbins 1967, ibmrd1104C.pdf; не открывал].
- Caillau et al. «Planar tilting maneuver of a spacecraft», arXiv:1504.06219 [П, аннотация+§1.3]: сингулярный стык ⇒ хаттеринг (бесконечно много переключений за конечное время, Fuller); даны достаточные условия на старт, когда сингулярных дуг нет; субоптимальная стратегия — заменить хаттеринг фиксированным числом кусочно-постоянных управлений.
Применимо: «внутренние» u нужны ровно на сингулярных дугах (когда [g_i,g_j]-скобки вырождены); проверка — обнуление функции переключения φ_i на интервале.

### П.5 Квантование
- Hante, arXiv:1509.04052, Lemma 1 (из Sager–Bock–Diehl 2012, [24] в тексте), Thm 7 [П]: для релаксированного β∈[0,1]^M, Σβ=1 существует кусочно-постоянное бинарное α с sup_t|∫(β−α)|≤(M−1)Δt (улучшено до O(log M)Δt); Thm 7: ‖y(β)−y(α)‖≤C·ε при ε-близости интегралов. Это для (полу)линейных гиперболических PDE; для ОДУ утверждение классическое (Sager), но здесь я его читал только в PDE-постановке.
- Обзор FCS-MPC / «Fast switching in MIOCP» (arXiv:2411.19300) [С].
Применимо: непрерывное u внутри коробки = выпуклая комбинация вершин; ШИМ с шагом Δt даёт ошибку состояния O(Δt) — т.е. «спектр» заменим вершинами, если шаг переключения мал относительно τ.

## Не нашлось
- Готовых констант/оценок «образ коробки за τ под потоком — зонотоп + ошибка» именно для планировщика-покрытия клетками.
- Интерполяции управлений между примитивами с гарантиями.
- Количественной потери оптимальности от конечного набора вершин (Frazzoli — open).
- Kurzhanski-эллипсоиды, funnel libraries Majumdar, CORA-документация не прочитаны.

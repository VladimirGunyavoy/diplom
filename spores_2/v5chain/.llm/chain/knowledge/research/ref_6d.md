# Эталон T для 6D (3 звена, manip3dyn) — hub-research-5, 2026-10-01
**Вопрос:** сетка 6D невозможна; чем сверять T коридора 6D (сейчас «верхняя оценка ±15%», hub-worker-8 note в JOURNAL)?
**Ответ:** прямой оптимизацией — multiple shooting CasADi/IPOPT со свободным T, u ∈ [−1,1]³, мультистарт по 8 ветвям 2π × 3–6 затравок.
Это **верхняя оценка T\*, практически точная** (сходится по N, лучшее значение находят десятки стартов из разных затравок); строгая нижняя
оценка дёшево получается только слабая (×0.15–0.55 от T) — для вилки не годится.
## Почему годится для слоёв
Динамика аффинна по τ, коробка |τ|≤1 = выпуклая оболочка 8 слоёв-углов ⇒ (теорема о релаксации, Filippov/Warga) inf T по углам = T\* по
коробке. Решения IPOPT на 88–95% интервалов имеют |u_i|=1 (bang-bang), т.е. эталон — та же структура, что у коридора.
IPOPT-сходимость = KKT дискретной задачи = дискретный ПМП (локальная оптимальность); глобальность — только эмпирически (мультистарт).
## Найдено попутно (важно для worker'а)
`corridor_nd.refine` **не держит |w| ≤ WM вдоль пути** (только конец в окне; WM проверяется лишь в узлах дерева). С ограничением |w|≤3
по пути эталон выше (q1 g0: 1.957 → 1.980; g.3 q1 2.737 → 2.745, q4 1.611 → 1.617) — коридор тогда «лучше эталона», т.е. решает
другую задачу. Сравнивать коридор надо с W50 (без предела); если WM — физический предел, добавить его в `gg` refine (ns точек, как clear).

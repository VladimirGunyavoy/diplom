# Растущие споры-клетки, отдельный атлас на каждое управление (hub-v5chain-research-13, 2026-10-05; идея и решения — пользователь, в диалоге)

**Вопрос.** Атлас из отдельных слоёв u ∈ {−1, 0, +1}: спора = нормальный отрезок (5 узлов), пронесённый потоком СВОЕГО управления вперёд и назад («бабочка» = клетка);
новая спора — только в непокрытое место, клетка растёт до соседей. Сколько спор нужно и какая точность?

**Ответ одной фразой.** ДИ: 258 спор (против 1509 у бабочек), 100% дошли, T/T* 1.023 / мед. 1.015; маятник: 282 споры (против 5000), 100/100, T/эталон 1.053 / мед. 1.018 —
при условии посева встык и обязательных боковых и курсовых пересечений клеток.

## Схема (прототипы `reports/research/di_grow_cells.py` — ДИ формулами; `grow_cells2d.py` — любая 2D система: rk4 + поиск четырёхугольника сетки узлов)
- Клетка: спора c, отрезок c + s·n (n ⟂ f(c, u)), M = 5 узлов поперёк (сетка на 10% шире отрезка), срезы по времени через DTN = .06 с, рост ≤ TMAX в каждую сторону.
- Посев встык (`ORDER`): следующая спора — вдоль потока за торцом готовой клетки и сбоку на ширину отрезка; случайная точка — только когда очередь пуста.
- Пересечения: сбоку отрезок заходит в соседа на OVL; по курсу рост идёт до первого ЦЕЛИКОМ покрытого среза (он остаётся перекрытием). Клетка нулевой длительности не добавляется.
- У равновесия своего потока (|f| < FMIN) клетки не строятся (ДИ u = 0: |v| < .2) — эти места накрывают другие атласы.
- Цена и агент — схема research-7 (`v7_spore_cells.md`): V(узел) = min_u [Δt + V*(φ_u(узел, Δt))], V*(точка) = min по клеткам любого атласа билинейно по 4 узлам; агент каждые Δt берёт argmin.
  Точная T* в методе не участвует (только оценка). Картинка шести сценариев счёта V — `v7/experiments/di/grow_cells/scenarios.py`.
- Адаптация размера (`ADAPT=1`, «гессиан потока», измеренный 5 клонами): рост останавливают изгиб среза > 5%, растяжение > ×2, перекос к потоку < 30°, поворот > 40°, путь > 1.2; короткая клетка → отрезок вдвое уже.

## (1) Адаптивное число клонов (столбцов) — MADAPT / MROW / MGRAM
- **Когда решается**: ОДИН раз, в конце роста клетки, не по ходу и не удаляя столбцы. Рост идёт на мелкой сетке (41 клон, KF) → готовая клетка получает m узлов поперёк: `G2D:371–390` (после `Cell(...)` на `:374`).
- **MADAPT=tol** (`G2D:263` флаг, `:375–382`): m ∈ (5, 9, 17, 33) по очереди; для каждого m берутся m равноотстоящих клонов `sn_=linspace(Sx[0],Sx[-1],m)`, ломаная торца по ним интерполируется (`np.interp`) на мелкую сетку Sx; dev = max по ВСЕМ строкам клетки (ilo..ihi) расстояния ломаной от строки мелкой сетки; первое m с dev ≤ MADAPT. Больше строки нет — только удвоение, вложенность 5⊂9⊂17⊂33. Результат `c.m`, счётчик `GSTAT['m_%d']`.
- **MROW=1** (`G2D:383–390`, `split_rows :423–448`, `trim_rows :449`): то же, но по каждой строке отдельно: `mrow[i]` = первое из 33→17→9→5 (перебор 17,9,5 вниз), при котором строка i отходит ≤ MADAPT; затем `min(mrow, m)`. Клетка режется на блоки строк (≥ MROWL=4, `:263`) со своим m: короткие блоки поднимаются до соседа с большим m или удлиняются за счёт соседей (`:430–441`, иначе бесконечный цикл — прогоны 80/81). Соседние блоки делят граничную строку; блок = прореживание столбцов `G[a:b+1, ::st]`, st=(m−1)/(m_блока−1) (`:443–445`).
- **MGRAM=κ** (`:391–398`): расстояние между соседними клонами в метрике грамиана клетки ≤ κ — НЕ работает: κ .5–2 → 1.053–1.060 (`nf_curved_ends.md` таблица «не работает»).
- **V новых столбцов**: отдельной интерполяции нет — каждый из m клонов это настоящий узел (траектория проинтегрирована, `Cell.build :39–57`; `BFINE=8` берёт каждый 8-й клон мелкой цепочки, `:43–47`), V считается в узлах обычным `solve :682`, внутри четырёхугольника билинейно. Стык блоков MROW: узел последней строки блока = первой строки следующего, связь `nxt` с рёбрами нулевого времени (`G2D:446–447`, `:696–700` — «без этой связи V отравляется BIG-углами»).
- **Числа** (жирные кольца, TMAX 8, SELFOV, DELTA выкл., BFINE 8, LOOK 20; 5 зёрен/зерно 0): 4 клона 1.035/285 кл./25k узлов; 5 — 1.030/239/27k; 9 — 1.018/241/54k; MADAPT .003 — 1.016/237/61k; **.001 — 1.0089/237/78k (атлас 80 с, solve 40 с)**; .0003 — 1.0084/260/96k. ## (2) Самоналожения по торцевому гало
- **Гало**: боковое HALO=.1 радиуса (`G2D:10,:39` — `sn` на (1+HALO)·r); торцевое в v8 — одна строка за ядром на **HALOT=.5 шага строки** (`GN8:137,:199–201`; `hf=hb=1, hfrac=HALOT`); в v7 торцевое гало — строка в `extra`.
- **SELFOV=1** (`G2D:263` флаг, `:349–353`; слово пользователя research-19): при ширине роста ihi−ilo ≥ 4 строится многоугольник уже выросшей части ЭТОЙ клетки (`MPath` по левому и правому краям строк lo_..hi_, исключая 2 строки у растущего торца: `(ilo, ihi−2)` для F, `(ilo+2, ihi)` для B); если новая строка торца попала внутрь (с копиями ±период `SH`) → `GSTAT['end_self']`, `extra[d]=1`, why='self'. «Наезжать на себя можно, но на гало — нет»: эта строка ДОБАВЛЯЕТСЯ (наложение в 1 строку), потом торец останавливается (`:372` `if d in extra: act[d]=False`).
- **endcov/FRAC/OWN** (`G2D:297–305,:368–372`): доля покрытой соседями новой строки торца `endcov(row,a,b)` (при OWN — только по своим столбцам, `cov0` = непокрытые в строке 0); `> FRAC` (.95 v7 / .5 main_pend) → `extra[d]=1` (ещё одна строка нахлёста), потом стоп; без `extra` — рост дальше.
- **Результат**: строгий стоп (0 строк) оставляет щели («лесенки» 287 кл. против 219); кольца с гало 1 строка без изгиба 1.022–1.065, с DELTA .06: 1.0100/507 кл. (−11% клеток к коротким 1.010/571) (`nf_curved_ends.md` п.6, 8).

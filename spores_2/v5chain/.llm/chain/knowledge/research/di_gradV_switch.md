# Переключение агента по ∇V из 5 точек клетки (DI) — hub-research-1, 2026-09-29
**Вопрос:** хватает ли V в 2n+1 = 5 точках клетки (спора, ±r поперёк поля, ±τ по потоку), чтобы агент переключался по знаку ∂V/∂v?
**Ответ:** да при мелких клетках (h = 0.1: 20/20 стартов в цель, время/T* mean 1.017, max 1.15); при крупных агент зависает у цели
(h = 0.4: 6/20, h = 0.2: 8/20) — нужна клетка цели со своим правилом (source_doc §4).
**Схема:** V = T* точный (проверяется только представление, не вычисление V); градиент — линейный МНК по 5 точкам; u = −sign(g_v);
клетка — ближайшая спора (сетка шага h, r = τ = h/2, оба слоя); агент dt = 0.01, стоп |(x, v)| < 0.05, лимит 3T*+1.
**Проверка:** `reports/research/di_gradV_switch.py` (+ `.json`), 20 стартов U[−2,2]², seed 0.
| h | дошли | время/T* mean / max | переключений (mean) |
|---|---|---|---|
| 0.4 | 6/20 | 1.036 / 1.068 | 63 |
| 0.2 | 8/20 | 1.017 / 1.040 | 25 |
| 0.1 | 20/20 | 1.017 / 1.150 | 13.5 |
Много переключений = скольжение по кривой переключения (она сама — траектория, скольжение по ней оптимально) + дребезг у цели.
Время у дошедших почти оптимально уже при h = 0.4 — ошибка не в переключении вдали, а в финише.
**Что нужно worker:** агент по ∇V из 2n+1 точек годится; обязательно — клетка цели (LQR/аналитика/поглотитель радиуса ~h),
иначе на крупных клетках агент не финиширует. Гипотеза (проверить): доля дошедших при h = 0.4 → 20/20 с поглотителем радиуса h.

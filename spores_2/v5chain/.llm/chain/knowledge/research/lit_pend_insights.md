## Где сидит проблема (картина)
- Сепаратриса = граница «успевает за k раскачек / k+1» (скачок V ≈ полпериода); стены идут ВДОЛЬ потока ⇒ клетки рядом короткие, у седла две линии сходятся крестом (`cut_walls.md`, «Итоги после 04:00»).
- Скопление спор у цели ×100 (1110 кл./ед.пл. против 11 вдали) — «гребёнка» стен CUT + медленный поток седла (`cut_walls.md` «Диагностика»: без CUT клеток 503 против 749 у цели <.6).
- Яма ширины среза w(t) клетки = проход НИЗА (w ∝ 1/|f| при u=0), а не седла; седло выдаёт только экспоненциальный рост у выходящей сепаратрисы (`nf_curved_ends.md` п.1).

## Топ-5 к переносу (порядок = мой совет; [Я] — оценка, не замер)
1. **NORMFRONT=2 + DELTA .06–.1 для pend** — env-флаги уже есть в v8, 0 строк; v7: .2→.06 = 1.021→1.010, клеток 391→571. Первый тест.
2. **SMAX 2 (+SLAM опц.) — стоп торца по расширению фронта**: 3–5 строк рядом с `bend` в `growN.py:~466/486`; v7: 1.026→1.016, max 1.42→1.25–1.33, +19% спор. Это ровно «остановка по расширению торца» из слова пользователя; для u=0-слоя проверить отдельно (w∝1/\|f\|, ложные стопы у низа).
3. **Финиш `finish_gen.shoot` в агент + exact_switch (σ-нуль) вместо шага Беллмана у переключения**: цель — хвост (p90 1.21 / max 2.4); v7: перекл. 39→1, T −6%, при ошибке модели нужен запас ±2%. Код `finish_gen.py` уже лежит в v8.
4. **CUTR-стена на сепаратрисе (2 прохода)**: самый дорогой и самый действенный против утечки V через барьер (1.050→1.028 при ×0.77 спор к простому CUT); без стен дефект V переходит в хвост. Перенос — отдельная работа: проход 0 + KD-дерево барьера + `cut_rollout` (v7 `compute.py:26–36`); использовать метку «число раскачек».

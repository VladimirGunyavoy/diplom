## 1. SafeCarGoal (статика)
- **Файл/шаг:** `env/safe_car_goal.py` (`SafeCarGoalEnv.step`), быстрый `env/safe_car_goal_numba.py` (parity — `safe_car_goal_numba_parity_check.py`). Дискретная кинематика (Эйлер), dt = 0.08.
- **Динамика:** θ ← θ + ω·dt; v ← clip((1−0.05)·v + a·dt, −1.0, 2.0); (x,y) ← (x,y) + v·dt·(cos θ, sin θ).
- **Состояние/управление:** obs 7D `[x, y, cos θ, sin θ, v, goal_dx, goal_dy]`; действие 2D `[a ∈ ±1.5, ω ∈ ±1.8]`.
- **Цель/окно:** goal (4.0, 3.6), радиус 0.45; эпизод кончается при успехе. Арена ±5.0 (выход — cost). Длина эпизода — `max_episode_steps` в конфиге jbench (не проверял число).
- **Препятствия:** 3 круга-хазарда r = 0.70, центры (0.0, 0.2), (1.8, 1.5), (−1.6, 2.3); cost = вход в круг/выход за арену; эпизод при cost не кончается (terminate_on_cost=False).
- **Спавн:** узкий, v0 = 0 у всех алгоритмов. Класс A — 3 геометрически плохих старта из 139 (симметрично исключаемы).
- **Лучший результат (30 сидов, 200k шагов, 100 эп./чекп.; `journal-2026/reports/research/car_tables_r6.md` §2а):** SAFE-HAC s20002: успех∧без нарушения ≥ 99% — 30/30 сидов, мед 76.8k шагов; 100% (T100) — 24/30, мед 96.0k (SAC-Lag 23/30, 124.8k). На конце: паритет с SAC-Lag.

## 2. SafeCarGoalDynamic (динамические препятствия)
- **Файл/шаг:** `env/safe_car_goal_dynamic.py`; рабочий вариант `env_variant=dynamic_timeline` + `hazard_aware_obs=true` — `env/safe_car_goal_dynamic_timeline_numba.py`. Машинка та же (dt 0.08, те же действия/цель).
- **Закон движения хазардов (детерминированный, шума нет):** t = 2π·step/180; offset_x = A_x·sin(t + φ), offset_y = A_y·cos(0.73·t + 1.7·φ); A = 0.42·(±1)·(1.0, 0.65) (знак чередуется по хазарду),
  φ_i = 0.35 + 2πi/3. Центры клипаются внутрь арены. `random_dynamic_obstacles=False` (условие статьи: фиксированные диски у всех); при True — фаза/амплитуда случайны на reset.
- **Наблюдение:** при `hazard_aware_obs` в obs добавлены положения хазардов (точный состав — в timeline_numba). Таймлайн хазардов непрерывный между эпизодами (`start_tick`); на эвале — общий таймлайн на чекпоинт.
- **Лучший результат (30 сидов, 200k; car_tables_r6.md §1а):** SAFE-HAC g0019: T90/T95/T99/T100 — 30/30 сидов, мед 51.2k / 57.6k / 67.2k / 83.2k шагов; SAC-Lag 28/30, T100 105.6k (p .001).

## 3. UnderwaterDrone
- **Файл/шаг:** `env/underwaterdrone.py` (gym-среда, шаг `TIME_STEP_SIZE` = 0.02 с), адаптер обучения `env/underwater_adapter.py`; в обучении action_repeat 5 (решение = 0.1 с), max_episode_steps 1500 шагов среды (= 300 решений).
- **Динамика:** 2D тело, масса 1.0, инерция 0.1, радиус 0.2, сопротивление 0.05, «гравитация» 0.5, тяга вдоль корпуса ±1.0 и боковая ±0.5 (плечо 0.2); пределы |v| ≤ 3, |ω| ≤ 3.
- **Состояние/управление:** состояние (x, y, θ, v_x, v_y, ω); obs 7D `[x, y, cos θ, sin θ, v_x, v_y, ω]` (+ 2 признака безопасности при `obs_safety_features`); действие 2D `[F_long ±1.0, F_lat ±0.5]`.
- **Цель/окно:** «лунка» в потолке: успех = центр дрона на y ≥ TOP_Y = 4.0 и |x| ≤ HOLE_WIDTH/2 = 0.4. Поле x ∈ [−3, 3], y ∈ [0, 4].
- **Препятствие (bad zone):** статичное, эллипс центр (−3.0, 2.0), полуоси a 4.0, b 1.0 + круг центр (1.0, 2.0), r 0.75 (если `with_circle_obstacle`); нарушение = вход центра (с учётом радиуса — см. `_obstacle_clearance`). Шума в динамике нет.
- **Лучший результат (`journal-2026/.llm/chain/STATUS.md`):** SAFE-HAC dr26d (500k шагов, n20): без щита V ≈ .005, clean ≈ .995 на (400k,500k]; с сертифицированным фолбэком (точная модель) — 0 нарушений, clean мед .94 (n10) против SAC-Lag .62.

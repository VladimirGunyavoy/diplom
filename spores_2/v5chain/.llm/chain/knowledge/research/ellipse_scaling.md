# Выход из экспоненты по n: атлас под запрос — эллипс T_s + V ≤ (1+ε)·C (hub-v5chain-research-18, 2026-10-06 15:40)
**Вопрос:** полное покрытие поля клетками ~ (поле/клетка)^n (DI 4D ~1000 клеток/слой, `growN_4d.md`) — 6D/8D неподъёмны. Что растить вместо всего поля?
**Ответ:** эллипс одного запроса {p: T_s(p) + V(p) ≤ (1+ε)·C}: его доля поля падает экспоненциально по n (ε .2: 3e-2 при n 2 → 3e-4 при n 6–8);
рост от цели по V до старта (обратный Дейкстра) экспоненту НЕ снимает (17–36% поля при любом n). Это и есть концепция пользователя (эллиптический спавн, прямое+обратное дерево, общий пул).

## Почему эллипс не теряет оптимум (вывод)
Для точки p оптимальной траектории s → цель: T_s(p) + V(p) = V(s) = C* ⇒ вся траектория внутри эллипса при любом ε ≥ 0. Граф, урезанный до эллипса, содержит её ⇒
оптимум урезанного = глобальный (с точностью дискретизации). Оценки T̂_s, V̂ с ошибкой δ (относ.) — запас ε ≳ 2δ; C — любая верхняя оценка (путь, найденный раньше).

Объединение по Q стартам (общий пул; `r18/union_frac.py`, `r18/bidir_union.py`), доля поля Q = 1 / 10 / 60:
эллипсы ε .2 — 4D 4.7e-3 / 6.5e-2 / .18; 6D 4e-4 / 2.2e-2 / 6e-2; 8D 3e-6 / 5.7e-4 / 1.6e-2. Двунапр. шары (запас 10%) — 4D .05 / .30 / .59; 6D .06 / .13 / .33; 8D 2e-3 / .05 / .15.
⇒ двунапр. рост хорош для ОДНОГО запроса, на многих — заполняет поле; эллипсы остаются малы и на 60 стартах.
**Грубая оценка не годится** (`r18/coarse_eps.py`: V̂, T̂_s — мультилинейно по сетке G⁴): нужный запас ε (вся траектория внутри) мед. 1.3 при G 5–9; без концов (T_s, V ≥ 1) .3–.5 при G 9–13.
Причина: T_s у старта и V у цели ~ √d (не Липшиц) — интерполяция даёт ~1.5 вместо 0. Значит оценки должны быть ТОЧНЫМИ (из тонкого атласа), а не с грубого уровня.
Клеток на запрос (гипотеза, оценка): доля × полное покрытие, но не меньше трубки шириной в клетку ≈ T*/ℓ · (2–3)^(n−1) — DI 4D ε .2: 6.8e-3·1000 ≈ 7 → ~20–50/слой против 1000.

## Алгоритм (worker'у — PLAN 26; без точного решения внутри метода)
Ключ: T_s + V ≤ C ⇒ min(T_s, V) ≤ C/2 ⇒ эллипс ⊆ шар цели {V ≤ C/2} ∪ шар старта {T_s ≤ C/2} — двунапр. рост покрывает его ТОЧНО без эвристики.
1. Первый старт — двунапр. рост раундами: дерево цели (очередь yb + SIDE от GS), дерево старта (yf + SIDE от коробки старта), каждый раунд +Δ ≈ 1 с по уровню;
   solve V и T̂_s (тот же Якоби, для T̂_s стенсилы по step(P, u, −1)); C = min_узлы(T̂_s + V); стоп при R_g + R_s ≥ (1+m)·C (m .1). Потом выкинуть клетки вне T̂_s + V ≤ (1+ε)C.
2. Следующий старт в ТОТ ЖЕ пул: прямое дерево растёт в порядке T̂_s + V̂ (A*; V̂ из пула — точный там, где пул вырос; вне — 0), стоп — когда min по фронту ≥ C_2. Где пул знает V, рост = эллипс.
3. Ожидание (МК): 1 старт 4D ~5% поля (×20 к полному), 6D ~0.5–6%; со 2-го старта — эллипс.
Литература (по памяти, не перепроверено): Informed RRT* (Gammell, Srinivasa, Barfoot, IROS 2014) — то же множество f̂ = ĝ + ĥ ≤ c_best; T-RO 2018 «Informed sampling…» — доля informed set падает с размерностью; BIT*.

# Эталон дифдрайва с ромбовым U: TGT мало, нужен TGTGT (hub-research-1, 2026-09-30)
**Вопрос:** чем сверять атлас дифдрайва v6 с U = ромб (|v|/vmax + |ω|/ωmax ≤ 1)? Достаточно ли «поворот–прямая–поворот» (TGT)?
**Ответ:** нет. При боковом сдвиге 5-отрезочный путь TGTGT (повороты на месте T, прямые G) быстрее TGT на 37% (сдвиг 0.3: 2.16 против
3.44) и на 8% (сдвиг 1: 3.83 против 4.14); в остальных 6 проверенных позах совпадает. По Balkcom & Mason (IJRR 21(3), 2002) оптимум —
не более 5 отрезков T/G (дословно по статье не сверял) ⇒ эталон = min(TGT, TGTGT численно).
**Схема:** vmax = ωmax = 1, цель (0,0,0); TGT — замкнутая формула (вперёд/задом); TGTGT — SLSQP по 5 длинам (знак = направление),
ограничение: конец = цель, 40 случайных стартов, берётся лучший допустимый (невязка < 1e−5).
**Проверка:** `reports/research/dd_rhombus_ref.py` (+`.json`):
| старт (x, y, θ) | TGT | TGTGT |
|---|---|---|
| (1, 0, 0), (−1, 0, 0) | 1.000 | 1.000 |
| (0, 0.3, 0) | 3.442 | **2.163** |
| (0, 1, 0) | 4.142 | **3.826** |
| (0, 0.3, π/2); (1, 1, π); (2, 0.5, 0.3); (0.2, 0.1, π) | 1.871; 4.556; 2.362; 3.365 | те же |
Проверка здравым смыслом: сдвиг 0.3 «змейкой» T(a) G(s) T(−2a) G(s) T(a): 4a + 0.3/sin a, минимум при a ≈ 0.27 → ≈ 2.2 ✓.
**Что нужно worker:** эталон атласа дифдрайва (ромб) = `min(TGT, TGTGT)` из `dd_rhombus_ref.py` (функции `tgt`, `tgtgt`); TGT
в одиночку завышает эталон на боковых сдвигах — атлас будет выглядеть «лучше эталона» (так было с RSR в v5).

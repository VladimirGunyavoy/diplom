# Дифдрайв: заготовка дизайна атласа (АТЛАС §8; по слову пользователя 2026-09-29 «подумай за ночь»)
Итог цели: граф над фазовым пространством → маршрут из произвольной точки → околооптимальная последовательность управлений.

## Неоднозначность (решить пользователю; до ответа делаем п.A — он верен в обоих случаях)
«(x y θ) (v ω)»: (A) v, ω — **управления** (кинематика, состояние 3D, режимы из таблицы §8); (B) v, ω — **часть состояния**
(состояние 5D, управления — ускорения a, α; прямое обобщение двойного интегратора: |a|≤a_max, |α|≤α_max).
Рекомендация: сначала A (3D, дёшево), B — только словом пользователя (5D-решётка тяжёлая).

## Схема A (кинематика, режимы §8)
Режимы: прямая (v=±vmax, ω=0), поворот на месте (v=0, ω=±ωmax), дуга (v=±vmax, ω=±ωmax). Состояние (x, y, θ).
- Узлы — state lattice: сетка (x, y) × θ по кругу (θ ∈ [0, 2π), период!), плюс начало/цель обязательно.
- Рёбра: из узла в каждом режиме по фиксированному «шагу» (длина/угол) → точка → `to_chart/from_chart` (точная, замкнутая форма
  для всех трёх режимов) → ближайшие узлы; cost = время. Для точного попадания — ветвления «шагов» к соседним узлам решётки.
- Дейкстра обратный от цели; политика = режим+шаг; запрос: интерполяция T по 8 углам ячейки (x, y, θ) (трилинейно, θ периодична).
- Эталон: Dubins/Reeds–Shepp для сравнения (у дифдрайва с v=±vmax, ωmax и разворотом на месте оптимум — комбинации поворот/прямая, эталон
  проще Dubins: поворот на месте + прямая + поворот на месте, время = |Δθ1|/ωmax + L/vmax + |Δθ2|/ωmax; проверить минимум по ориентации).
- Отладка: сначала ограничение до 1D (только прямая) и до 2D (x, θ), потом 3D.
## Шаги
A1 `src/atlas_dd/` — Mode-интерфейс + три режима, тест to_chart∘from_chart = id; A2 state lattice + рёбра + Дейкстра; A3 эталон
(поворот-прямая-поворот) и замер ошибки в узлах/между; A4 запрос + извлечение последовательности управлений; A5 адаптивные споры.

- RSR-эталон (`reference.py`) — НЕ граница: T_граф − T_RSR ∈ [−0.99, +0.85], mean +0.13 (минус — граф использует 2 прямые; плюс — дискретность курсов). Нужен A3b: сходимость по плотности решётки.
- A3b сходимость по шагу (поле [−3,3]², 16 курсов, T на общих узлах, T_грубая − T_тонкая): h=1→0.5: mean 0.024, max 0.38; h=0.5→0.25: mean 0.00075, max 0.146. Монотонно (тонкая ≤ грубой), сходится; предел — потолок модели (16 курсов, без дуг), не истинный оптимум.
- A2b (дуги) — трудность: конец дуги (хорда 2R·sin(Δθ/2) вдоль среднего курса, R = vmax/ωmax) в узел решётки не попадает. Варианты: (1) интерполяция T в конечной точке (трилинейно по (x, y, θ), θ периодична) — как в атласе DI; (2) подбор h и курсов под R. Рекомендация: (1), она же нужна для запроса из произвольной точки (A4). Делать следующим звеном.
- A4-запрос: `interp_T3` (билинейно по (x,y) на двух соседних курсах + линейно по θ, циклически). В узлах = T. Точки на решётке h=0.25 с курсом из набора vs T решётки h=0.25 (интерполянт от h=1): mean 0.079, max 0.785 (~π/4 — излом у цели/курсов; включает дискретность h=1: mean 0.024). Дальше: дуги с интерполяцией (A2b), A5 адаптация.
- A2b дуги: `arc_sweeps` — дуги между соседними курсами (точный конец через Arc.from_chart), T в конце — interp_T3, итерации Беллмана от Дейкстры. Поле [−6,6]², h=1: 46 итераций, 17 с, средний выигрыш против «поворот/прямая» 0.68, max 1.61; нижняя граница max(d/vmax,|θ|/ωmax) не нарушена, узлы вроде (3,0,курс 0) остались T=3. Осторожно: интерполяция в конце дуги не даёт гарантий (не Дейкстра), сходимость по h для арок не проверена. Тест `tests/test_atlas_dd_arcs.py` (n=3).
- A4 `plan.rollout` (жадно по interp_T3, 8 режимов, dt=0.25): на поле T с дугами из 15 случайных стартов [−4,4]²×θ приходит в 0.10–0.32 от цели по (x,y), 0.01–0.12 рад по θ, время ≈ 0.86·T (останавливается, когда T перестаёт падать, ~1 шаг до цели).

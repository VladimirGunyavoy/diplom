# roles/ — память ролей этого проекта
У каждой роли своя папка: что делали прошлые звенья этой роли, без чтения всей истории. Общие правила — в
`~/claude-work/system/llm/ARCHITECTURE_CURRENT.md` §Память ролей и проекта; здесь только данные проекта.

| файл | что это | кто пишет | когда читать |
|---|---|---|---|
| `<роль>/HANDOFF.md` | живой хендофф, ≤ 100 строк, заменять, не дописывать | текущее звено роли | всегда на §Старт |
| `<роль>/recent.md` | последние 5 смен роли, 3–6 строк на смену, новые сверху | следующее звено, когда раскладывает хендофф | на §Старт, бегло |
| `<роль>/archive.md` | всё, что старше | переносится из `recent.md` | только за конкретной справкой |

Роли: `worker/`, `research/`, `searcher/`, `dispatcher/` (+ `handoffs/` — старые файлы смен), `fixer/`, `meta/`, `yoga/`.

Общая история проекта — не здесь, а в `../chain/`: `JOURNAL.md` (события всех ролей, одна строка на событие), `STATUS.md`,
`PLAN.md` (+ `history/plan_archive.md`), `ISSUES.md`, `knowledge/`, `history/decisions.md`. Её кратко читают все роли, дальше
каждая идёт в свою папку.

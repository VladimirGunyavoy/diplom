# (B) Рецепт круга на дроне: V=время на графе обратного дерева + жадный агент (w38; подбор STARTSEED 1, сиды 20–29, 1000 стартов; тест не трогали)
Код: `bench/w38_drone/w38_V.py` (+`wv.sh`), на aida a37. Граф — узлы обратного дерева (NB 6000, RHOB .3), рёбра = 4 слоя × шаг HV (Эйлер .02), итерация ценностей V=min[HV+V̂(q)], V̂=min_k V+KV·d; цель V=0. Агент: перебор DEP шагов вперёд по модели (зазор ≥ PAD+.02 в каждой Эйлер-точке, границы, **потолок среды**), лист оценивается V̂; план проверяет `verify`. Без SLSQP.
**Находки:** (1) в среде есть потолок (y>4 вне лунки — отскок); без него в модели агента ~65 «касаний» — следствие, а не расхождение моделей; (2) одношаговый фильтр даёт stuck (нужен lookahead); (3) плотность дерева (NB 6k…1M, RHOB .3….12) на охват не влияет (60–70 из 100 при DEP2, дерево насыщается по RHOB).

V при KV≈3 не завышена, при KV 6 завышена (1.55 > агент 1.25: lookahead по модели исправляет V). Потеря — не граф: T/Tкор растёт с укорочением горизонта (DEP 3→4→5: 1.31→1.25→1.18).
**F5 — SLSQP-дожим плана агента (REFINE=1, 1 попытка, +~17 мс):** s20–21: T/Tкор мед 1.234 (было 1.309 на DEP3) — переключения уточняются, топология остаётся агентская ⇒ узкое место — ТОПОЛОГИЯ (число/порядок переключений), не моменты.
**Вывод:** критерий +3–5% не достигнут: лучший 1.18 при 23 мс/шаг (DEP5) / ~1.23 с дожимом; охват 99% при DEP4. Лидирует глубина поиска, т.е. агент сходится к планировщику. Не пробовано: beam вместо полного перебора 4^DEP (DEP 8 за те же мс), KV 3 + DEP≥4.

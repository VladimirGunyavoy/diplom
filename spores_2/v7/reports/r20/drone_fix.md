# Дрон R20 — лечение недошедших стартов (worker-37)
Код — копия b17 (`bench/w37_drone/`: spores_drone_e_w37.py, corridor_nd_w37.py с параметром vfy, dr.sh); запуск `dr.sh TAG "ENV…" сиды`; агрегат `agg_drone.py <папка>`. Данные: bench/data/drone_r20_fix{,v}/.
## Диагноз (по json R20 + DIAG на срезе подбора)
- no_path, тип A (90, 50): стыки есть (206–216 попаданий), но топ-5 топологий SLSQP отвергает → лечится K=20 (больше топологий).
- no_path, тип B (28, 3): стыка нет (nh=0) — прямое дерево NF1600 без направления не доходит на длинных маршрутах (T_OCP 6–7 с) → A*-эвристика прямого дерева HFW·(G_b ближайшего узла обратного дерева + расстояние); без OCP.
- touch (35 из 67; старты 79, 51, 58, 34): refine «ок», а проверка среды (Эйлер .02) даёт касание в узле шага (глубина до −3.6, т.е. план проходит сквозь препятствие) → отбрасывать кандидатов, не прошедших проверку среды, до выбора лучшего (VFY=1).

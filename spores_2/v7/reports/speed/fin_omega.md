# FIN-ω (b9, 2026-10-13): финиш-дуги не выходят за коробку состояний

Причина (c3/CA4): `shoot_pol` проверял только конец дуг ⇒ путь мог нарушать |ω| ≤ WM (T_agent < T_ref за счёт нарушения).
Правка: `finish_gen.FREE` (функция «состояние допустимо») проверяется по всему пути: `shoot_grid` — кумулятивно вдоль каждой дуги (alive-маски), `shoot_pol` — после доводки SLSQP по подшагам HS=.02 (иначе остаётся решение сетки);
`growN.rollout`: `FINBOX` (по умолч. 1 для manip, 0 для остальных систем) — `FREE = inbox & free`. Старт вне допустимого → финиш не идёт.
Замер (g300so, V_base, 20 стартов OCP r23, VF 2 FINGRID 2; `~/spore_v5/b9/finw.py`):
| FINBOX | дошли | T/эт мед / mean / max | отличаются |
|---|---|---|---|
| 0 (как было) | 20/20 | 1.056 / 1.090 / 1.502 | — |
| 1 | 20/20 | 1.062 / 1.108 / 1.502 | старты 3 (T 3.08→3.88), 10 (2.65→2.70), 17 (2.10→2.24) — финиш нарушал |ω| |
Т.е. 3/20 «выигрышей» прежнего финиша были нарушением |ω|; честная цифра manip 4D теперь 1.062/1.108/1.502. `FINGRID=0` (`shoot`, SLSQP по всем топологиям) путь не проверяет.

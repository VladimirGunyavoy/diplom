# LLM Context Directory

**Last updated:** 2026-03-19

## 🎯 Главная цель

**Минимизировать размер контекста** при передаче знаний между диалогами с AI агентами, сохраняя **адекватность информации** для эффективной работы.

**Принцип:** Агент читает только то, что нужно для текущей задачи, а не весь проект целиком.

---

Эта директория содержит структурированный контекст для передачи знаний между диалогами с AI агентами.

## 📖 Порядок чтения для нового агента

1. **[AGENT_START.md](AGENT_START.md)** - 🚀 НАЧНИ ЗДЕСЬ! Напутствие и важные правила
2. **[context/start_prompt.md](context/start_prompt.md)** - Краткий контекст проекта
3. **[state/current.md](state/current.md)** - Текущее состояние проекта
4. **[state/plan.md](state/plan.md)** - Текущий план работы
5. **[context/architecture.md](context/architecture.md)** - Детали архитектуры (при необходимости)

## 📁 Структура

```
llm/
├── README.md                    # Этот файл - навигация
├── AGENT_START.md              # Напутствие для нового агента
├── AGENT_END_ROUTINE.md        # Чеклист действий в конце работы
├── .llmignore                  # Что не включать в контекст
│
├── context/                     # Контекст проекта (редко меняется)
│   ├── start_prompt.md         # Краткая выжимка
│   ├── architecture.md         # Архитектура и паттерны
│   ├── code_snippets.md        # Важные куски кода
│   └── dependencies.md         # Граф зависимостей
│
├── state/                       # Текущее состояние (часто меняется)
│   ├── current.md              # Что работает, что в процессе
│   ├── issues.md               # Баги и проблемы
│   └── plan.md                 # План и прогресс
│
├── history/                     # История (append-only)
│   ├── changelog.md            # Структурированная история
│   └── decisions.md            # Архитектурные решения
│
└── tools/                       # Вспомогательные скрипты
    └── update_changelog.py     # Помощник для обновления changelog
```

## 🔄 Workflow

### Начало работы:
1. Прочитать `AGENT_START.md`
2. Изучить текущее состояние (`state/`)
3. Приступить к задаче

### Конец работы:
Следовать чеклисту из `AGENT_END_ROUTINE.md`

## 🎯 Назначение файлов

| Файл | Частота изменений | Назначение |
|------|------------------|------------|
| `context/*` | Редко | Базовые знания о проекте |
| `state/*` | Часто | Актуальное состояние |
| `history/*` | Append-only | Не удалять, только добавлять |
| `AGENT_START.md` | По мере накопления опыта | Важные инсайты |

## 🚫 .llmignore

Используется для исключения больших/неактуальных файлов из контекста агента.

# Token Usage Stats

> Статистика расхода токенов по сессиям (шкала Cursor, 0-100%).
> Заполняется в две части: T_START/T_AFTER — стартовой рутиной, T_BEFORE_END/T_END — финишной (см. Decision #20).

---

## Как читать

- **T_START** — % токенов в начале сессии, до стартовой рутины
- **T_AFTER** — % токенов после стартовой рутины, перед началом задачи
- **T_BEFORE_END** — % токенов после задачи, до финишной рутины
- **T_END** — % токенов после финишной рутины (конец сессии)
- **Рутина↑** = T_AFTER − T_START (стартовая рутина)
- **Работа** = T_BEFORE_END − T_AFTER
- **Рутина↓** = T_END − T_BEFORE_END (финишная рутина)

Для сессий 9-16 (протокол v1, рутина была только в конце) Рутина↑ и T_AFTER не измерялись — `T_AFTER = T_START`, `Рутина↑ = -`. Старые "До рутины"/"После рутины" соответствуют T_BEFORE_END/T_END.

Код: `src/algo/growN.py` — env `ZSOFT` (умолч. 0 = как было, проверено: заезд/слои/solve8 при ZSOFT=0 совпали с базой побитно по таблицам), `ZSOFTLA` (0 — по заданию; 1 — look-ahead, см. ниже). `HexIdx.both()` теперь обёртка над `both_r()` (+ наименьший r задетого ядра). Сводка: `tests/zsoft_table.py`.
Правило (по заданию): `stat()` при st==2 для любой клетки, пока заход от первого касания (pos − t0) < ZSOFT·h, h = 2·w1·w2/(w1+w2), w1 — ширина ядра своей клетки, w2 — задетого соседа (несколько — min); ветка ZOVMAX тогда выключена. Слой 0/±1: u=+1/−1/0 в таблицах; посевы stats_layers 0..4, solve8 seed 0, 200 стартов, M=3, E3 lin, политика look.
**Находка:** заход меряется по сетке боковых узлов, шаг `S[1]−S[0]` = .05, и «pos − t0 < ZSOFT·h» при касании всегда истинно (pos = t0) ⇒ при любом ZSOFT>0 клетка делает минимум один шаг (.05) за касание: ZSOFT .05 и .1 дают одно и то же. Чтобы ZSOFT работал непрерывно, добавлен `ZSOFTLA=1`: шаг делается, только если заход ПОСЛЕ шага ≤ ZSOFT·h (вторая таблица).
Заезд: клетка 1 = спора цели (ширина ядра .364), 2/3 — соседи (ширина .91). «Ядро 1 в ядрах 2+3» — доля площади ядра клетки 1.

# runs/ — журналы запусков окна v8 (src/runlog.py)

На каждый запуск окна (main.py) — папка `runs/<ГГГГММДД-ЧЧММСС>/` (при совпадении секунды — суффикс `-2`). Данные локальные (`.gitignore`), этот README — в git. Запись идёт в фоновом потоке, окно не тормозит. Эталон T_ref в журнал не пишется.

| Файл | Что |
|---|---|
| `params.json` | все параметры: `growN` (константы верхнего регистра: ZSOFT, ZSOFTLA, GM, M, RHO, KF, DELTA, …), `env` (SYS, M, ETOL, …, VSURF_*), `vsurf`, `solve8` (политики агента), слои, коммит git (`git.commit`, `git.dirty`), время старта |
| `grow.log` | консоль окна дублем: `[stop]`/`[cell]` роста, `[vsurf]`, `[stepper]`, `[runlog]` |
| `atlas.json` | по слоям u: `cells`, `rows`, `nodes`, `M`; `uncovered` (непокрытая доля на остановке слоя) и `overlap_last` (средний нахлёст последних затравок) — из строк роста; `t_done_s` — момент завершения слоя от старта окна; пересохраняется при изменении набора клеток |
| `vcalc.jsonl` | строка на каждый расчёт V: `mode` (v / q / qquad — клавиша Y), `cache` (`miss` — считали, `hit` — из кэша, `total_s`=0), `cells`, `nodes`, `passes`, `converged`, `solve_s`, `total_s`, `finite` (доля узлов с конечным V), `vmax`. Возврат к прежнему режиму из кэша строки не пишет |
| `traj_<режим>.csv` | 300 стартов (клавиша T; `VSURF_TRAJ_N`) для режима расчёта: `x0,v0,status,left_work_area` (путь хоть раз вышел за рабочее поле ±XL)`,prephase` (старт был без V*: путь начинается потоком слоя до V* или до выхода за область)`,T,switches,share_u+1,share_u-1,share_u0` (доля записей пути под управлением; запись каждого 3-го шага), `end_x,end_v` у недошедших. `status`: `reached` / `failed` (в области, но не дошёл) / `out_of_area` (у старта нет V*: любая траектория выходит за выращенную область — не считается и не рисуется; путь рисуется до выхода, конец — маркер на границе) |
| `traj_summary.jsonl` | строка на счёт траекторий: `mode`, `n`, `in_area`, `out_of_area`, `reached`, `failed`, `T_median`, `T_p90`, `switches_mean` (по всем, кроме out_of_area), `work` (то же только по траекториям, целиком оставшимся в ±XL), `left_work_area`, `prephase_starts`, `seconds` |
| `keys.log` | `время_с<TAB>клавиша<TAB>состояние ПОСЛЕ нажатия` (V/B/K/T/Y/7/8/9, шаги N/M/C/Z/X/G, мышь); состояние: режимы V/B, вид траекторий, расчёт Y, скелет, видимость слоёв 7/8/9; плюс `ms` — время отклика на нажатие (вся отрисовка), `vcalc` (`hit` из кэша / `miss` считали / `same` ключ не менялся), `traj_data` (`cached`/`computed`), `mesh_hit`/`mesh_built` — слоёв мешей, оставленных как есть / пересобранных |
| `summary.json` | сводка запуска (обновляется по событиям) |
| `runs/index.jsonl` | общий: по строке `summary.json` каждого запуска — для сравнения запусков |

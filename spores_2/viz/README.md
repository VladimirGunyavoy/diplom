# viz — pygame-визуализации систем «по-человечески» (слово пользователя 2026-10-13 ~14:25)
Слово пользователя: «pygame визуализации для систем; человеческая визуализация, а не фазовая плоскость; первый приоритет».
Системы: маятник, двойной маятник; дифдрайв без препятствий и с препятствиями; машина с препятствиями и без; манипуляторы
(«для многомерного просто проекция, нет времени на норм 3D»). Спецификацию составил hub-v5chain-research-27; код — линии D и B.

## Что должно получиться
Одна команда на систему: `python viz/play.py <система>` — окно, в котором сама система движется в рабочем пространстве (стержни,
тележка, машинка, звенья), видны цель, препятствия/запреты и след; играется готовая траектория, посчитанная заранее.
Просмотрщик зависит ТОЛЬКО от pygame + numpy + json (пользователь запускает на ноуте после `git pull`, без aida, GPU и кода спор).

## Формат данных — `viz/data/<система>.json` (один файл на систему, < 1 МБ, коммитится)
```
{"sys": "pend", "title": "Маятник, |u| ≤ 0.3", "params": {...длины, радиусы, габариты...},
 "goal": {...}, "obstacles": [{"type": "disc", "c": [x, y], "r": r} | {"type": "box", ...} | {"type": "halfplane", ...}],
 "episodes": [{"method": "споры", "start": 3, "dt": 0.02, "X": [[...состояние...], ...], "U": [[...], ...],
               "T": 2.31, "T_ref": 2.25, "ok": true}, ...]}
```
- `X` — состояния с постоянным шагом `dt` (0.02 с; пересчёт единым проверяльщиком `bench/common.py: Env.step` по (u_k, dt_k) метода), `U` — управление на шаге.
- На старт — эпизоды нескольких методов (споры, эталон/OCP, при наличии PPO): сравнение «призраком».
- 4–6 стартов на систему, выбирать показательные (длинные, с раскачкой/объездом), а не первые попавшиеся; провал метода показывать честно (`ok: false`).

## Общий плеер — `viz/viz_core.py` (линия D, ПЕРВЫМ делом, пуш в течение ~30 мин)
`run(sysname, draw, data)`; `draw(surf, cam, params, x, u, t)` рисует одно состояние; ядро делает остальное:
- воспроизведение в реальном времени; **Пробел** пауза, **R** сначала, **←/→** старт, **↑/↓** скорость ×0.25…×4, **M** метод / **G** призрак эталона вкл-выкл, **Esc** выход;
- след конца звена/центра тележки, цель (полупрозрачное окно/поза), подпись: система, метод, t / T, T/T_ref, полоски управлений u_i ∈ [−1, 1];
- призрак: эталон полупрозрачным поверх основного метода, общие часы — видно, кто приходит раньше;
- без экрана (хаб): `python viz/play.py <система> --png out_dir` (SDL_VIDEODRIVER=dummy) — кадры/раскадровка для проверки агентом; `--gif` по возможности.
- `cam`: мир → экран (масштаб, центр, ось y вверх). Окно 1280×720, сглаженные линии, читаемый шрифт, светлый фон.

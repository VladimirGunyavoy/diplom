## Общее (из брифа — не отступать)
- Файлы: `reports/anim/anim_<система>_<что>_s<индекс старта>.mp4` + `.gif`, 1260×900, 6–12 с, бесшовный цикл (пауза ~1 с на финале, затем сначала).
- Белый фон. SPORE — янтарный `#E8A317`, толстая линия; конкуренты — `#2E7D6B`, `#8FB9A8`, серый `#6B7C76`; препятствия/запреты — светло-серая заливка; цель — зелёный контур.
- Шрифт ≥ 20 px. Подписи методов — у самих траекторий, без легенды. В углу — T каждого метода. Все методы в ОДНОМ кадре на общих часах.
- Только траектории, прошедшие единый проверяльщик (RK4, шаг .01) — та же (u_k, dt_k), что засчитана в таблице.
- Старт — с T/T_ref SPORE около медианы (не лучший). Метод не дошёл — крестик там, где остановился. 6D с целями и 8D — пометка «preliminary» в углу.
- Манифест `reports/anim/manifest.md`: файл → система → индекс старта → T и T/T_ref каждого показанного метода (строку добавляет тот, кто сделал файл).

## Рендер — `viz/anim.py` (линия B, b13, ПЕРВЫМ делом)
`python viz/anim.py <имя_анимации>` → mp4 + gif. На хабе ffmpeg нет: `pip install imageio imageio-ffmpeg` (бинарник внутри пакета), кадры — pygame без экрана.
Тема презентации — отдельным набором цветов/шрифтов; рисовалки систем (`draw_links.py`, `draw_mobile.py`, `draw_arm2.py`) должны принимать цвет и подпись метода параметром.
Описание анимации — словарь в `viz/anims.py`: система, старт, список (метод → цвет → подпись), длительность, «preliminary», счётчик целей.

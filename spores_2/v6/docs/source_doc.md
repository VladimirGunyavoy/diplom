## 1. Идея
Система ẋ = f(x, u). Берём только крайние управления u₁…u_K (для быстродействия по принципу максимума оптимум — bang-bang).
Каждое u_k — **слой** с полем F_k(x) = f(x, u_k). Фазовое пространство покрываем **клетками** — небольшими плотными областями,
вытянутыми вдоль траекторий одного слоя. Клетки перекрываются: это **атлас, а не плитка**. **Агент** (точка) движется по клеткам
и в любой момент может перейти в клетку-соседа другого слоя (= переключить управление). Выход метода — **коридор**: последовательность
(dt_i, u_i) от старта к цели, которую затем доводит оптимизатор. Критерий обобщённый; сейчас — время. [решено]

## 2. Термины [решено]
- **Слой** — одно крайнее управление u_k. **Спора** — центр, из которого выросла клетка. **Клетка** — плотная область вокруг споры.
- **Сегмент** — отрезок (в n-мерии — (n−1)-мерная площадка) через спору перпендикулярно полю, в нормированных координатах (§7).
- **Стены** — траектории краёв сегмента. **Вход / выход (торцы)** — сегмент, унесённый потоком на −τ / +τ.
  На картинке v4 клетка — кривой четырёхугольник: две стороны со стрелками — стены, две поперечные — вход и выход.
- **Фронты** — сегмент, унесённый на kτ/n_tau (поперечные линии внутри клетки, режим TIME в v4).
- **Соседи** — клетки, пересекающиеся с данной. **Агент** — точка, путешествующая по клеткам (как в RL: агент + критик V).
- **Core / halo** — ядро клетки и запасная оболочка вокруг него (§5).

## 3. Клетка
Построение (как `ortho_grid.py`, режим TIME): спора → сегмент ±r поперёк поля → интегрирование краёв (и промежуточных точек)
вперёд и назад на τ → стены, фронты, вход и выход. Гарантия по построению: стены сотканы из траекторий, изнутри их не пересечь
(теорема единственности, flow box); неточность только в представлении (конечное число траекторий).
**Размер:** конечный, небольшой, даже если клетка могла бы быть большой [решено]. Ограничители: растяжение сегмента ρ_max
(длина выхода / длина сегмента), r_max, τ_max. **Угол поворота поля — не критерий** (на DI поле вдоль параболы поворачивается почти
на 90° без вреда; «Phase-Atlas» §3 — угол только эвристика сеяния).
**Двойной интегратор** (ẋ = v, v̇ = u, |u| ≤ 1): поток при постоянном u аффинный ⇒ вход/выход — прямые отрезки, стены — параболы.
Центр (0, 0), u = +1: сегмент горизонтален, не растягивается, стены x = ±r + t²/2. Центр (0, 2): длина торца / длина сегмента =
0.89 / 1.0 / 1.61 при t = 0.5 / 1 / 2 — длину клетки ограничивает ρ_max.

## 4. Цена V и переключение
- **V хранится по клеткам** [решено], не во всех точках (дорого; в будущем — нейросеть; V — первое приближение критика).
- **Где внутри клетки:** центр + центры граней = **2n+1 точек** [research] (углов 2ⁿ — только для n ≤ 3). Даёт градиент ∇V центральными
  разностями и диагональ гессиана; растёт линейно по n.
- **Цена продолжения** Q_k(x) = время до выхода клетки + V на выходе. Вдоль потока внутри клетки Q_k **точно линейна**:
  Q_k(через t) = Q_k(сейчас) − t ⇒ точки нужны только поперёк потока. V = min_k Q_k по клеткам, содержащим точку.
- **Переключаться можно в любой момент** [решено]. Правило [research]: по принципу максимума u = argmin_k ⟨∇V, F_k(x)⟩; момент
  переключения внутри клетки — корень функции переключения (DI: смена знака ∂V/∂v) вдоль траектории, а не перебор фронтов.
- **Почему важна точность момента** (проверено, DI, из (−2, 0) в (0, 0), T* = 2.83): опоздание переключения на δ стоит
  0.86 / 1.28 / 1.96 с при δ = 0.05 / 0.1 / 0.2 — потеря ≈ 4√δ (проскок цели на ε стоит ≈ 2√ε на возврат).
  Для коридора это снимает оптимизатор (dt_i непрерывны); для исполнения агентом — корень ∇V.
- **Плотность точек поперёк** — по гессиану [research]: шаг hᵢ = √(8·tol/|λᵢ|) по главным направлениям гессиана Q_k
  (анизотропная адаптация сеток; Alauzet, Loseille — [проверить]). Где гессиан бесконечен — **излом** V на кривой переключения и
  **корень** у цели — не мельчить: нижний предел шага h_min, излом хранить как min двух гладких Q (в v5 это дало max ошибки
  0.278 → 0.159, mean −31%), цель — отдельная клетка со своей формулой/LQR.
- **Гарантии попадания нет** — агент проверяет свой путь: прошёл → посмотрел, где оказался → дальше. Условие покрытия: выход каждой
  клетки лежит в ядрах соседей; нет — дыра, туда сеять новую спору («притирка»).

## 5. Core / halo
В атласе (перекрывающиеся клетки) нужны в любой размерности: выход клетки должен лежать внутри соседа с запасом, иначе численная
ошибка выбросит агента в дыру. Вторая роль гало — запас на такт управления: толщина ≥ τ_ctrl·|F| (DI, v = 2, τ_ctrl = 0.05: ≈ 0.11).
В v5 гало не нужно — там плитка с точными общими границами.

## 6. Построение атласа (эллипс) [решено]
Эллипс с фокусами старт/цель, сначала почти отрезок. Клетки максимально допустимого размера в старте и цели, затем заполнение между
ними; клетки притираются друг к другу. Пути нет — растёт эксцентриситет. Приоритет спавна — как A*: (от старта + до цели),
лучше во времени [research]. Эллипс — эвристика **только для центров спор**; тело клетки может выходить за эллипс.

## 7. Нормировка [решено: по умолчанию так, вернуться позже]
Перпендикуляр к полю зависит от масштаба осей. По умолчанию: L — размер области, T — собственное (характерное) время системы —
за сколько система заметно меняет состояние (маятник √(l/g); пружина 1/ω; DI — своего ритма нет, T ≈ √(L/a_max); в общем случае
1/типичное собственное число якобиана или L/типичная скорость). Позиции / L, скорости / (L/T). DI, поле 4, a = 1: x/4, v/2.
В Ursina — клавиша масштаба оси скорости, смотреть глазами. Запасной вариант — автоматическая балансировка якобиана.

## 8. Коридор → оптимизатор [решено]
Коридор = (dt_i, u_i). Оптимизация моментов переключения при фиксированной последовательности управлений — известный приём
(Kaya & Noakes, time-optimal switching — [проверить]). V по клеткам — эвристика A*-поиска коридора; ∇V — начальное приближение
сопряжённых переменных для оптимизатора. Поле V как в v5 (обратная связь из любой точки) — второй, вспомогательный выход.

## 9. Слабые места
1. Интерполяция V между опорными точками — болезнь v5 на дифдрайве (цена не сходится по h, 5D: +45–50% пока рёбра не в узлах);
   здесь смягчается оптимизатором коридора, но для исполнения агентом остаётся.
2. Экспонента по размерности (2ⁿ углов → берём 2n+1); неголономные боковые сдвиги — цепочками переключений внутри клеток.
3. Гиперболические зоны (маятник у верхней точки): растяжение e^{λt} — лечится малым ρ_max и замкнутым исполнением агентом.
4. Параметры не исчезли: r, τ, n_tau, ρ_max, S (L, T), α (core/halo), tol, h_min.

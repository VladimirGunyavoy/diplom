# Mathematical Foundations of Reachability Analysis for Controlled Pendulum Systems

## 1. Introduction

The primary objective of this project is the construction and optimization of a reachability graph within the phase space of a controlled pendulum. Constructing a complete reachability graph is a fundamental problem in control theory, but it is often computationally prohibitive due to the "curse of dimensionality" and the complexity of integrating system dynamics.

This work introduces a novel method to address this challenge by focusing on the inherent symmetries within the control fields. Instead of exhaustively exploring the state space, we build a local reachability set using a tree-like structure of control sequences. The core of the method lies in identifying and exploiting symmetries, which manifest as different control sequences leading to nearby points in the phase space.

By formulating this as an optimization problem, we can adjust the control durations to force these symmetric paths to converge precisely while simultaneously maximizing the area of the local reachability set. This approach yields a conservative but computationally efficient estimate of the reachable set, which forms a valid and optimized subgraph of the global reachability graph. This document outlines the mathematical principles underpinning this methodology, from optimal control theory to the specific optimization techniques employed.

## 2. Theoretical Background

### 2.1. The Pendulum System Dynamics

The system under consideration is a damped pendulum actuated by a torque control. The state of the system is described by its angle $\theta$ and angular velocity $\omega$. The dynamics are governed by a set of first-order ordinary differential equations:

$ \dot{\theta} = \omega $
$ \dot{\omega} = -b\omega - k\sin(\theta) + a u(t) $

Where:
- $x(t) = [\theta(t), \omega(t)]^T$ is the state vector in the phase space.
- $u(t)$ is the control input (torque), which is bounded: $u(t) \in [-U_{max}, U_{max}]$.
- $b$ is the damping coefficient.
- $k = g/L$ is a constant related to gravity $g$ and pendulum length $L$.
- $a = 1/(mL^2)$ is a constant related to mass $m$ and length $L$.

The system is a nonlinear, second-order control system. The goal is to drive the system from an initial state $x_0$ to a target state or region by choosing an optimal control function $u(t)$.

### 2.2. Pontryagin's Maximum Principle (PMP)

Pontryagin's Maximum Principle provides necessary conditions for a control to be optimal for a given cost function. For a general system $\dot{x} = f(x, u)$, the principle introduces a costate vector $\psi(t)$ and a Hamiltonian function $H(x, \psi, u)$.

$ H(x, \psi, u) = \psi^T f(x, u) + L(x, u) $

Where $L(x, u)$ is the cost function integrand. For time-optimal control, $L(x, u) = 1$. The principle states that for an optimal control $u^*(t)$ and the corresponding trajectory $x^*(t)$, there exists a costate $\psi^*(t)$ such that:

1.  **Costate Equation**: $ \dot{\psi}^* = -\nabla_x H(x^*, \psi^*, u^*) $
2.  **Maximization Condition**: $ H(x^*, \psi^*, u^*) \ge H(x^*, \psi^*, u) $ for all admissible controls $u$ at almost every time $t$.

For the pendulum system with bounded control, the control-dependent part of the Hamiltonian is linear in $u$: $H = ... + \psi_\omega a u(t)$. To maximize $H$, the control $u^*(t)$ must be chosen at its bounds:

$ u^*(t) = U_{max} \cdot \text{sgn}(\psi_\omega(t)) $

This is a **bang-bang control**, meaning the optimal control strategy consists of applying the maximum or minimum available torque, switching between them at specific moments. The function $\psi_\omega(t)$ is called the switching function. This result is crucial as it significantly simplifies the search for optimal controls: instead of searching over an infinite-dimensional space of functions, we only need to find the optimal switching times.

### 2.3. Reachability Analysis

A reachability set is the set of all states that can be reached from a given initial state $x_0$ at a certain time $T$ using all admissible control functions. For a system with an $n$-dimensional state space, the boundary of the local reachability set is typically formed by trajectories generated by control sequences with at most $n-1$ switches.

For the pendulum ($n=2$), the local reachability set is bounded by trajectories with at most one switch. This means we can explore the boundary of what's reachable by applying sequences of two bang-bang controls, e.g., $(+U_{max} \text{ for } t_1, -U_{max} \text{ for } t_2)$. This project leverages this principle to construct local reachable sets in a structured manner.

## 3. Methodology: Tree-Based Optimization of Reachable Sets

The core of the proposed method is to construct and optimize a local reachable set by exploring a tree of bang-bang control sequences.

### 3.1. Constructing the Control Tree

Starting from a point $x_0$ in the phase space, we build a tree structure representing the application of sequential bang-bang controls:

-   **Root**: The initial state $x_0$.
-   **Children**: The states reached from $x_0$ by applying a single control segment for a duration $dt_c$. For the pendulum, there are two primary controls ($+U_{max}$ and $-U_{max}$), leading to two children. The project seems to explore four children, likely representing forward and backward integration in time, or control applied to different initial velocity signs.
-   **Grandchildren**: The states reached from each child by applying a second control segment for a duration $dt_{gc}$. Each child branches out, creating a set of grandchildren.

This two-level tree represents a discrete approximation of the local reachability set boundary, formed by control sequences with one switch.

### 3.2. Identifying Symmetries through Grandchildren Pairing

The key insight is that different paths through the tree (i.e., different control sequences) can lead to the same or very close points in the phase space. This phenomenon represents a symmetry in the control field. For example, the sequence $(+U_{max} \text{ for } t_1, -U_{max} \text{ for } t_2)$ might result in the same final state as a different sequence $(-U_{max} \text{ for } t_3, +U_{max} \text{ for } t_4)$.

The algorithm explicitly searches for these symmetries by identifying pairs of "grandchildren" nodes in the tree that are spatially close in the phase space. These pairs are candidates for convergence.

### 3.3. Optimization Problem Formulation

Instead of just finding existing symmetries, the method actively creates them by optimizing the control durations ($dt$ values) to force the paired grandchildren to meet at a single point. This is framed as a formal optimization problem:

-   **Objective Function**: To maximize the area of the convex hull formed by the grandchildren's positions in the phase space. This is equivalent to maximizing the "volume" of the estimated local reachable set. To fit standard minimization algorithms, the problem is formulated as minimizing the negative area.

-   **Variables**: The optimization variables are the time durations of the control segments, forming a vector $DT = [dt_{c,1}, ..., dt_{c,4}, dt_{gc,1}, ..., dt_{gc,8}]$.

-   **Constraints**: The primary constraints enforce the identified symmetries. For each pair of grandchildren $(p_i, p_j)$ that should converge, a constraint is added to ensure their Euclidean distance in the phase space is zero (or less than a small tolerance $\epsilon$).

The optimization problem can be stated as:

$ \underset{DT}{\text{maximize}} \quad \text{Area}(\text{hull}(p_1(DT), p_2(DT), ..., p_k(DT))) $

$ \text{subject to} \quad ||p_i(DT) - p_j(DT)||_2 \le \epsilon \quad \forall (i, j) \in \text{PairedGrandchildren} $

$ dt_{min} \le dt_i \le dt_{max} \quad \forall dt_i \in DT $

where $p_k(DT)$ is the phase space position of the k-th grandchild, which is a function of the control duration vector $DT$. This problem is solved using numerical optimization techniques, such as Sequential Least Squares Programming (SLSQP), to find the optimal control durations that define the largest possible local reachable set with the desired convergence properties.

### 3.4. Scientific Novelty and Relation to Existing Work

The scientific novelty of this methodology lies in its unique synthesis of numerical optimization with geometric control concepts to perform a constructive reachability analysis. While many existing methods for reachability analysis focus on either exhaustive grid-based exploration or finding the outer boundary of the reachable set, this approach takes a different path.

Conventional methods often fall into several categories:
-   **Grid-based methods** (e.g., solving Hamilton-Jacobi-Bellman equations) provide accurate results but are computationally intractable for systems with more than a few dimensions.
-   **Set-propagation techniques** (using support functions, ellipsoids, or zonotopes) are efficient but often provide coarse over-approximations of the true reachable set, especially for nonlinear systems.
-   **Optimization-based boundary finding** methods typically solve a series of optimal control problems to find the extremal points of the reachable set in various directions.

This project introduces a novel concept of **"enforced symmetrization"**. Instead of passively accepting the system's dynamics, the algorithm actively shapes the local reachable set. It identifies potential, approximate symmetries in the control sequences and then uses optimization to transform them into exact symmetries by forcing different trajectories to converge.

The primary novelty is twofold:
1.  **Constructive vs. Descriptive:** Unlike methods that describe the boundary of a reachable set, this approach *constructs* an optimized, internal subgraph of the reachability graph. This "tiling" strategy, where each tile is a locally optimal and symmetric structure, offers a more scalable way to explore the state space.
2.  **Integrated Optimization Goal:** The optimization does not merely seek convergence. It simultaneously maximizes the *area* of the local set, ensuring that the resulting subgraph element is as informative as possible. This dual objective of enforcing symmetry while maximizing volume is a unique formulation.

This method can be seen as a practical, algorithmic bridge between the high-level concepts of geometric control theory (exploring flows along Lie brackets) and the concrete task of generating a reachability graph. It provides a computationally feasible alternative to both exhaustive search and purely analytical techniques, representing a significant and novel contribution to the field of computational control theory.

## 4. Connection to Symmetries and Lie Groups

The process of identifying and enforcing the convergence of different control paths is deeply connected to the concept of symmetries in dynamical systems.

### 4.1. Symmetries in Control Systems

A symmetry in a control system is a transformation of the state space that preserves the system's dynamics. If a system is symmetric under a certain transformation, then for any trajectory, a transformed version of that trajectory is also a valid trajectory of the system.

In this project, the "symmetries" we identify are not perfect, continuous symmetries in the classical sense but are discrete and approximate. The fact that two different control sequences, like `(+U, -U)` and `(-U, +U)`, can lead to nearby points suggests an underlying symmetric structure in the vector fields generated by the controls. The optimization process can be viewed as a method to find parameters (the `dt` values) that make these symmetries exact for a specific set of paths.

### 4.2. Lie Groups and System Controllability

While the implementation does not explicitly compute Lie brackets, the underlying theory is relevant. Lie groups and their associated Lie algebras provide a powerful framework for analyzing the controllability of nonlinear systems. The controllability of a system is related to the Lie algebra generated by the vector fields corresponding to the available controls.

For the pendulum, we have two primary vector fields, $f_1(x) = f(x, +U_{max})$ and $f_2(x) = f(x, -U_{max})$. The Lie bracket of these two vector fields, $[f_1, f_2]$, represents a new direction of motion that can be achieved by rapidly switching between the two controls. By computing successive Lie brackets, we can span the entire set of possible directions of motion in the state space.

The tree-based approach can be seen as a numerical exploration of the directions generated by these Lie brackets. By building sequences of controls, we are essentially approximating the flows along these combined vector fields. The optimization that forces grandchildren to converge is, in essence, finding specific combinations of flows that cancel each other out in certain directions, thus defining a precise boundary of the reachable set. This provides a constructive, numerical alternative to the purely algebraic approach of computing the full Lie algebra.

## 5. Conclusion

This project presents a sophisticated, computationally-grounded method for constructing local reachable sets for a nonlinear control system. By leveraging fundamental principles from optimal control theory, specifically the bang-bang nature of time-optimal controls derived from Pontryagin's Maximum Principle, the search space is effectively discretized.

The core innovation lies in the tree-based exploration of control sequences and the subsequent optimization stage. The identification of approximate symmetries and the use of numerical optimization to enforce exact convergence provides a powerful tool for understanding the geometry of the reachable set. This approach not only generates a conservative estimate of the reachable set but also produces an optimized subgraph that can be seamlessly integrated into a larger, global reachability graph.

The methodology serves as a bridge between abstract control theory, including concepts of Lie algebras and system controllability, and practical, implementable algorithms. It provides a scalable way to tackle the complexity of reachability analysis, paving the way for more efficient motion planning and control synthesis for complex dynamical systems.

## 6. Future Work: Generalization to Higher Dimensions and Overcoming the Curse of Dimensionality

A critical question for any reachability analysis method is its scalability to higher-dimensional systems. A naive generalization of the tree-building approach presented here would inevitably succumb to the "curse of dimensionality," as the number of nodes in the control tree grows exponentially with the required depth (which is related to the system's dimension, $n$). However, the geometric and algebraic nature of this methodology offers a sophisticated path to mitigate this challenge, distinguishing it from conventional grid-based methods.

The key to scalability lies in moving from a purely numerical, brute-force search for symmetries to a theoretically informed, analytical approach. Two promising directions for future research are:

1.  **Analytically Guided Pairing via Lie Commutators:** Instead of geometrically searching for all pairs of nearby grandchildren, one can analytically pre-select control sequences that are known to be candidates for symmetry. Based on geometric control theory (specifically, the Baker-Campbell-Hausdorff formula), sequences of controls that approximate motion along Lie brackets are natural candidates. For example, the difference between applying controls $(A, B)$ versus $(B, A)$ is related to their Lie bracket $[A, B]$. The search for symmetries then becomes a more focused, numerical problem of solving $x_{AB}(T_A, T_B) - x_{BA}(T_B, T_A) = 0$ for the control durations. This transforms the problem from a combinatorial search for pairs to solving a well-defined system of nonlinear equations, drastically reducing the search space.

2.  **Control Basis Decomposition and Pairing in Coefficient Space:** A more profound generalization involves decomposing complex control sequences into a canonical basis of the control Lie algebra. Any local motion can be represented as a linear combination of motions along these basis vector fields (e.g., $f_{+U}$, $f_{-U}$, $[f_{+U}, f_{-U}]$, etc.). The search for symmetries is thus lifted from the state space into the lower-dimensional space of basis coefficients. Symmetries can be identified structurally, for instance, by pairing sequences corresponding to opposite vertices of a hypercube in this coefficient space. This approach replaces a complex geometric problem with a structured, canonical algebraic one.

These strategies directly combat the curse of dimensionality more effectively than traditional methods. Unlike grid-based approaches, whose complexity scales exponentially with the state-space dimension, the complexity of this algebraic approach scales with the structural complexity of the system's control algebra. By exploiting the inherent geometric structure of the problem, this method avoids the exponential partitioning of the state space, offering a more scalable and computationally tractable path for analyzing the reachability of high-dimensional nonlinear systems.

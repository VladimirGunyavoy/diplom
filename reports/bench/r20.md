## Круг — V = дисконтированная НАГРАДА среды (worker-b23; `envs2026.md` §b23, код `reports/bench/b23/canal_val.py`, json `canal_val_*.json`) — до ревью senior

То же кольцевое 4D обратное дерево (NB 600k), но V узла — дисконтированная сумма награды среды r = v_кас/(1+|ρ−1.5|) (модель агента — та же формула), итерация ценностей (max, γ на шаг .02 = .98), V̂(q) = max по K ближайшим (V_b − KV·|q−b|); стены — запрещённые узлы + фильтр v2; агент — argmax (награда + γ⁵V̂). Без R*/v* — орбита выбирается сама.
- Подбор γ × KV (24 строки `selT_*`) — только эп. 100000–09 × деревья 20–29; выбор γ .98, KV .3.
- **Их протокол (20 эп. 200000–19): 38.50 ± 1.06 (pop SD), cost 0, мин 35.32** — против safe-MHLB 34.47 ± 1.30, SAC-Lag 33.98 ± 5.14, TD3 27.84 ± 1.90 и нашей канавы 34.4–34.9.

- **Формулировка (ревью senior-1):** «круг в метрике среды, планирование по модели: 38.5 ± 1.1 на их протоколе, 38.4 ± 2.9 на 2000 эпизодов (1 со штрафом); опорные числа коллег 34.5 (не перепроверены, короткое обучение)». Оговорки: (1) RL — из непроверенного документа коллег при бюджете 100–200k шагов — это НЕ сравнение с доведённым RL, а «выше опорных чисел коллег при их бюджете обучения»; с литературой **не сверено** (1 запрос: таблица SafePO в приложении arXiv 2310.12567 без чисел в выдаче; стандартный протокол SG — без обрыва на стене и с лимитом cost — напрямую не сравним). (2) Мы планируем по МОДЕЛИ среды (point.xml), RL учится без модели — сравнение «планирование по известной модели против обучения без модели». (3) R20 — не cost 0: 1/2000 со штрафом (разбор — b23), 11 эп. с return < 20, дерево 12 — 34.78.
- **Правдоподобие — верхняя оценка (research-33, замер в MuJoCo SafetyPointCircle2, aida 1):** награда шага = 0.1 · v_кас / (1 + |ρ − 1.5|) (код `circle_level0.calculate_reward`, reward_factor .1, R круга 1.5), 500 шагов. Скорость Point по прямой 1.50 м/с (90% за 59 шагов); на круговой орбите скорость падает с радиусом (уст. режим u = [1, w]): ρ .29 → .86 м/с, .44 → 1.01, .92 → 1.24, 1.32 → 1.36, 1.53 → 1.43. Лучшая круговая орбита внутри стен — ρ = 1.125, v ≈ 1.30: 0.1 · 1.30 / 1.375 · 500 = **47.4** (с отступом .03: ρ 1.095, v 1.295 → **46.1**); без учёта разгона со старта. **38.5 = 81–84% от оценки** (RL коллег 34.5 = 73–75%) — правдоподобно, не > 100%. Сверка: канава с R* = .8 имеет потолок 0.1 · 1.18 / 1.70 · 500 = 34.8 и получила 34.4–34.9 — упёрлась в собственную орбиту, её ограничивал выбор R*. Некруговые пути (углы квадрата, ρ до 1.59) могут чуть превысить 47; абсолютный потолок 0.1 · 1.5 · 500 = 75 недостижим (ρ = 1.5 только в углах).
- Проверено research-33 в коде: return = сумма НАСТОЯЩЕЙ награды MuJoCo-среды по `env.step`, выход |x| или |y| > 1.125 → −1, cost, обрыв (их обёртка); 500 шагов. **Не досчитано:** нативный cost среды (`c` из `env.step`) и safety margin в json — просил b23.
